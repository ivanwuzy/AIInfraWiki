## Overview

唯一研究主体为**苏州库瀚信息科技有限公司**。该主体已进入破产程序：苏州工业园区人民法院于 **2024-05-30** 受理破产清算，管理人申请后法院宣告破产，相关公告于 **2025-06-30** 公开。故其不具备普通股权投资、生产采购或商业合作标的的前提；研究仅保留为破产管理人依法处分下、权属和可维护性均待核验的特定资产机会。

## 主体、历史路线与分类边界

- **主体边界：** 仅限苏州库瀚信息科技有限公司；报告记载其成立于 **2017-12-26**。不将品牌、创始人/法定代表人、苏州/硅谷/南京历史研发点，或历史产品名称迁入其他法人。
- **历史路线：** 公开材料最高仅支持企业级 SSD 存储主控、SPU 和分布式存储软件的研发/产业化叙事。2020 年材料称 PCIe Gen5 SSD 主控完成核心功能 FPGA 验证并计划流片量产；2021 年融资报道涉及 SPU 与 LSE；2022 年宣传称 Aurora 主控流片和 SPU 关键 IP 验证。这些分别是历史披露或公司宣传，不能证明量产、订单、收入、客户验收、IP 权属或现有维护团队。
- **主分类：** [8 其他](../segments/8-其他.md)——企业级存储控制芯片/存储系统软件的历史路线；现有目录没有适配的稳定二级分类。
- **不纳入：** `1.14 其他AI芯片架构`、`1.6 存算一体/近存计算芯片`、`1.9 Scale-out互联通信`、`2.1 加速计算平台`、`2.2 AI算子开发` 或 `3.6 集群管理软件`。SPU 的名称或与 DPU 的概念类比，不构成已交付的 AI 芯片、网络产品或软件平台。

## 破产与商业化边界

法院裁定记录，截至 **2024-05-30** 的审计口径资产总额为 **19,177,388.09 元**、负债总额为 **66,596,719.81 元**、净资产为 **-47,419,331.72 元**；管理人实际接管资产为 **1,729,726.72 元**，审核确认债权为 **59,592,878.75 元**。审计资产与实际接管资产对应不同口径，均不能充当 IP 估值、现金余额或可收购资产清单。

报告未找到该主体对外销售 SPU、Aurora SSD、LSE/LPSE 或存储系统方案的具名订单、验收、发票或回款证据；“两个头部云厂商联合研发”、目标客户群和融资新闻亦不能升级为客户、收入、当前股权或可处分技术成果。破产宣告不等于全部技术无价值或 IP 已出售，但将技术风险转化为资产处分、权属、许可和维护连续性风险。

## 对机器人基础设施的行动判断

库瀚历史路线最多可关联训练数据湖、传感器日志归档、检查点读写和离线回放，不能替代训练 GPU、端侧推理 SoC、关节控制器或功能安全链路。

| 选项 | 当前判断 | 重新开启条件 |
|---|---|---|
| 股权投资 / 整体并购 | 不建议 | 新的独立主体须重新完成 IP、团队、产品、收入、控制权及可转移性尽调。 |
| 合作 / 生产采购 | 不建议 | 新主体拥有持续供货、非关联客户验收、备件、保修和漏洞响应后，按新供应商准入。 |
| 特定资产收购 | 条件性观察 | 管理人具有合法处分权，且资产权属清晰、资料可复现、维护团队可合法承接并优于替代路径。 |

优先使用具备 SLA、固件更新、RMA 与第二来源的企业级 SSD，以及 SPDK/Ceph 等可维护基线。任何潜在资产包只可在隔离环境开展可退出 PoC，不进入生产训练集群、生产 BOM 或机器人安全链路。

## 风险、反证与关键未知

| 事项 | 现有证据 | 结论与处理 |
|---|---|---|
| 历史产品工程化 | FPGA 验证、流片和 IP 验证主要是计划或宣传口径 | 不视为量产、可采购 SKU 或可转让 RTL；获取样片、固件、验证环境和复现材料。 |
| 软件与 IP 可交易性 | LPSE/LSE/KH-LSE 名称相近，但无版本谱系、代码、著作权或许可证材料 | 不纳入资产估值；逐项审计源码、SBOM、第三方依赖及处分权。 |
| 破产资产可承接性 | 已确认破产与资产接管 | 未取得资产清册、负担、合同、员工和处置文件；不假定低价且无瑕疵取得。 |
| 商业化 | 融资报道与目标市场叙事存在 | 无具名订单、验收、收入或回款；不赋予商业化价值。 |

## 下一步验证

1. **P0 法律与权属：** 向破产管理人取得资产清册、评估/拍卖文件、债权人决议和逐项处分授权，区分破产财产、租赁物、质押物、客户定制物及个人物品。
2. **P0 技术与许可：** 核验专利、商标、软著、RTL、代码、固件、样片、文档与数据的登记、职务发明、开源 SBOM、EDA/IP 核/NAND/协议许可及合同限制。
3. **P1 可复现性：** 在隔离环境重建工具链、仿真/FPGA/样片、固件签名、升级与回滚，并以机器人日志、检查点与回放负载对比企业级 SSD 加 SPDK/Ceph 基线。
4. **P1 维护性：** 审查核心人员可合法聘用性、测试覆盖、依赖、供应替代、断电/盘故障恢复、漏洞响应和至少两年维护成本。
