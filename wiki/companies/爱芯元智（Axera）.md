## Overview

爱芯元智是一家把混合精度 NPU、AI-ISP、视频/图像处理和 SDK 整合进端侧、边缘与汽车 SoC 的中国无晶圆厂公司，于 **2026-02** 在港交所主板挂牌（股份代码 **0600**）。其核心价值不在于替代数据中心训练 GPU，而在于让相机、边缘盒子、辅助驾驶域控和正在成形的具身终端在功耗、图像质量与本地推理之间取得可量产的折中。2025 年收入 **5.617 亿元**、毛利 **1.213 亿元**、年内亏损 **11.842 亿元**、经调整年内亏损 **6.345 亿元**，收入同比增长 **18.8%**，但尚未盈利。对人形机器人公司，它应作为“端侧视觉/边缘推理战略观察与 POC 标的”，而非机器人基础模型训练的算力标的。

## 业务与产品定位

- 唯一主二级分类为 `1.3 NPU（ASIC）`。理由：爱芯当前可验证的收入承载物和产品重心是面向终端计算、边缘计算和智能汽车的 AI 推理 SoC，核心计算 IP 是“爱芯通元”混合精度 NPU，产品价值通过端/边推理、视觉理解和车载/机器视觉 SoC 交付实现。它不是 GPGPU：公开资料不支持其承担通用 GPU 集群训练；也不是 1.4 图形 GPU：图形渲染、显示 API 和工作站交付并非主营。
- **不建议强加次分类。** Pulsar2 是重要的软件护城河，但公开能力集中于自家 NPU 的模型转换、量化和端侧部署，尚未呈现 `2.1` 要求的训练/后训练、自定义计算扩展、多卡通信和跨代开发者平台完整度；AI-ISP 也没有对应的现有二级标签。`2.1` 不要求软件独立收费或跨厂商中立，未入选的原因是功能边界而非商业模式。
- 总表建议：维持“1.3 NPU（ASIC）”，描述更新为“视觉/边缘/车载 AI 推理 SoC（混合精度 NPU＋AI-ISP）；Pulsar2 为自有端侧工具链，当前未达到 2.1 门槛”。
- 产品线分三线：视觉终端（AXProton AI-ISP、AX630A/AX620A/AX170A/AX630C/AX620Q）、汽车（M55H/M76H/M97）、边缘推理（AX650N、AX8850/AX8850N、机器视觉 SoC AX8910）。
- NPU 演进：V1（2019）偏 CNN，V3（2021）原生支持 BEV+Transformer，V5（2023）优化 Transformer/BEV，V6（2024）支持多模态大模型，V7（2025）开放 DSL、对接 PyTorch/SGlang，并提出 C2C scale-up。
- 软件入口：Pulsar2 工具链负责模型转译、优化和部署；公司与百度飞桨于 **2022-10** 完成 AX620A I 级兼容性测试；维护 `AXERA-TECH` GitHub 组织与 `ax-llm`、`ax-samples` 开源项目。
- 官网称 NPU“原生支持 DeepSeek、Qwen、Llama 等 LLM/VLM”，这只支持“可尝试部署”而非“能无差异运行所有模型”，须按公司主张对待，不作为采购性能承诺。

## 纵向演进

- **2019-05** 公司成立；董事长兼执行董事仇肖莘（QIU Xiaoxin）于 **2021-03** 加入，此前于 **2001-01 至 2016-07** 任职 Broadcom 体系。
- 2020-04 完成 Pre-A，2020-05 第一代 AX630A 流片、2020-08 点亮（“仅用九个月”等措辞为公司自述）；AX630A 于 **2021-05** 投入量产。
- 2021-07 第二代 AX620A 流片/点亮；AX170A 称于 **2022-03** 进入消费领域。
- 融资（严格保留原口径，以招股书历史融资表为主，媒体累计口径不作审计事实）：Pre-A 对价约 **7,000 万元**（2020-04-24 协议日）；A 约 **2.64 亿元**；A+ 约 **7.55 亿元**及 2021 股权转让约 **1.843 亿元**；A++ 官网“数亿元”/表中约 **8.00 亿元**；B 约 **3.998 亿元**及 2023 股权转让约 **1.637 亿元**；C 轮官网称 **2025-04“超十亿元”**、表中对价约 **13.364 亿元**、新增注册资本约 **7,266.5 万元**。
- **2023-03** 发布 AX650N、招股书列 **2023-09** 投入量产；M55H 于 **2022-07** 获 AEC-Q 认证、**2023-03** 整车量产，M76H 于 **2023-12** 获 AEC-Q100 Grade 2 认证；**2023-11** 发布智能汽车业务战略。
- **2025-04** 完成“超十亿元”C 轮融资；**2025-05** 发布边缘智能芯片 AX8850 并宣布边缘计算战略。
- **2026-02** 港交所主板挂牌，代码 **0600**。2025 年报：收入 **5.617 亿元**（2024 年 **4.729 亿元**）、毛利 **1.213 亿元**（2024 年 **0.994 亿元**）、年内亏损 **11.842 亿元**（2024 年 **9.042 亿元**）、经调整年内亏损 **6.345 亿元**（2024 年 **6.277 亿元**）；主要 SoC 出货 **2.12 亿颗**，其中全年芯片出货 **8,600 万颗**、智能汽车 SoC 出货 **63 万颗**。
- 年报称 2025 年汽车业务 design-in 数量创历史新高，M97 于 **2025-10** 投产并在 **2026-02** 开始量产；design-in 不是已确认收入，M97 的最终客户、量产爬坡和毛利须待后续验证。

## 对机器人战略的含义

### 采购与合作

建议推进 POC，并明确岗位划分：**训练不适合**（无公开集群通信、HBM、分布式训练生态或大规模预训练客户证据）；**在线推理适合做分层 POC**（对低时延视觉检测、跟踪、分割、固定结构 Transformer、相机前处理与部分量化 VLM，AX650N/AX8850 值得压测，建议把“机身感知协处理器”与“中央决策计算单元”拆开，前者才是爱芯可能有 TCO 优势的位置）；**数据闭环可能有价值**（AI-ISP 改善暗光/HDR 输入、芯片侧可做事件触发、初筛、压缩与隐私前处理，但不是训练数据平台）。与 Jetson、瑞芯微、地平线、Ambarella 及 x86+独显/感知上云五条路径做同机位横向比较。

### 投资与并购

**战略投资为观察，满足条件后再议**（已上市、信息透明；当前亏损大、机器人订单证据不足）。**整体并购不建议**（上市公司、多业务线、车规承诺与整合成本高，训练侧协同弱；除非公司战略性剥离“机器人边缘感知/工具链”业务且具备可独立团队、IP 边界与长期供货承诺）。采购/合作先推进：通过 8—12 周 POC，目标感知任务精度不低于基线、端到端 p95 延迟/功耗达标、连续运行稳定、BSP 可维护。

### 自研芯片启示

爱芯证明视觉 SoC 需要 ISP、NPU、SDK、量产生态的长期协同，复制成本高，**暂不建议以爱芯为唯一参照做全栈自研**；只有在年出货、相机链路差异化和长期算力需求达到阈值，且能确定团队、流片、软件、认证及供应链投入时才考虑。自研应从我方机器人推理/视觉/控制负载倒推，而非复制通用视觉 SoC 路线。

## 风险、反证与未知项

- 公司尚未盈利，2025 年收入增长但亏损扩大，体现多产品线并进的资本强度；低 ASP 大批量视觉芯片与高研发/资本开支并存。
- 公开 GitHub 和官网材料未发现足以代表大规模第三方用户的、可复现且长期的机器人生产体验集合，尤其缺少对 AX650N/AX8850 在 VLM、VLA、多摄同步、vLLM/SGlang 类服务、断电恢复和连续数周热稳定性上的独立测试；不能把“没有负面 issue”解读为“没有问题”，也不能把公开示例跑通解读为“已达到工业 SLA”。
- 车规认证与量产定点、整车功能安全不是同一件事；AEC-Q100 是器件可靠性测试体系，不自动证明 ADAS 算法性能或持续订单。汽车 63 万颗出货不能直接外推为机器人能力。
- 供应链安全为中性偏正但必须验证：“国产”不是供应安全审计结论；公开资料不足以证明晶圆、封测、关键 IP、DDR/存储及车规元件完全无单点风险。
- 合作方（原力灵机、声网）的具身/机器人合作与实时互动方案为新的协同线索，而非已验证的机器人规模订单；应视为可约谈、索要 benchmark 和 joint demo 的信息，不把新闻合作描述为营收贡献。
