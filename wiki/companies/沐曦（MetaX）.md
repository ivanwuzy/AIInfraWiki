## Overview

沐曦集成电路（上海）股份有限公司（MetaX，科创板 `688802`）是一家中国 Fabless 云端通用 GPU（GPGPU）公司，2020-09 在上海成立，以曦云 C 系列覆盖训练/推理/科学计算，以 MetaXLink 提供 2–128 卡互连，以 MXMACA 尝试降低 CUDA 应用迁移成本。对人形机器人公司，它是云端 VLA/VLM 训练、仿真数据与分布式推理的候选第二供应商，而非机载端侧芯片方案；其价值取决于真实工作负载的 CUDA 迁移成本和集群稳定性验证，以及 `C600` 国产供应链量产兑现。

## 业务与产品定位

- 主分类为 `1.1 GPGPU（AI GPU）`，次分类为 `2.1 加速计算平台（CUDA-like）`。公司公开价值创造是设计并销售用于训练、推理与通用计算的 GPU 板卡、服务器和集群；MXMACA 围绕 CUDA 应用迁移、主流框架、模型适配、MetaXLink 多卡互联和集群部署形成平台，按现行平台完整度与潜力标准达到成长型 2.1 门槛。软件不独立订阅不影响平台资格，兼容范围和开发者开放度继续作为成熟度问题。
- 三线产品按场景划分：曦思 N 系列面向云端/边端推理和视频处理；曦云 C500/C600 面向训练、推理和科学计算；曦彩 G100 面向云游戏、数字孪生与专业制图，**仍处于研发中**，不能视为可采购的机器人仿真卡。补充报告还将曦索 X 系列列入公司产品矩阵，但没有披露其规格、量产状态或机器人适配证据，故不将其当作可采购能力。
- 2025 年营业收入 `16.440855 亿元`，同比增长 `121.26%`；归母净利润 `-7.894463 亿元`，亏损同**比收窄 `43.97%`**；研发投入 `10.273929 亿元`、占营收 `62.49%`。截至 2025 年末，公司称 GPU 累计销量超过 `55,000` 颗、部署于 10 余个智算集群，覆盖国家级公共算力平台、运营商平台和商业智算中心。
- C500 公开规格为 `64GB` 高带宽显存、全链路 ECC、2/4 卡 MetaXLink、最小 `1%` 颗粒度虚拟化和最大 `350W` 功耗，兼容 x86/Arm、Ubuntu/CentOS/麒麟，提供 `mx-smi`、`mx-report`、日志导出、容器与虚拟化章节。这些是 PoC 配置输入，不是性能承诺。

## 纵向演进

- `2020-09`：公司在上海成立。创始人[陈维良](../people/陈维良.md)任董事长、总经理，联合创始人[彭莉](../people/彭莉.md)负责硬件架构、[杨建](../people/杨建.md)负责软件架构；三人核心团队均有 [AMD](../institutions/AMD.md) 上海研发体系任职背景（2007—2020 年前后），是"AMD 上海核心技术人员创业"的典型案例。2025 年报称三人具备 GPU 设计、量产与软件生态经历，研发团队 `675` 人、占员工 `73%`。创业选择通用 GPU 而非单一 ASIC，从起步同时覆盖 AI 训练/推理、通用/科学计算与未来图形渲染。
- 融资：`2021-01-20` Pre-A（红杉中国领投，真格、和利、天津泰达跟投）；`2021-03-08` Pre-A+（经纬、光速联合领投，和利、红杉、真格跟投）；截至 `2021-11` 公司称成立以来已完成多轮共数十亿元人民币融资。逐轮私募金额与估值未全部披露，媒体“百亿估值”未写入事实。

## 对机器人战略的含义

### 采购与合作

优先级高于图形优先厂商，但应先做非排他 PoC。以 C500/C600 少量采购起步，在固定模型、数据、精度、并行策略和功耗下，与 NVIDIA/AMD/摩尔线程在同一机器人工作负载上做 A/B：VLA/VLM 后训练、仿真数据管线、模型量化推理、2–128 卡通信、故障恢复与混合 GPU 调度。验收门槛包括代码修改量、缺失算子数、数值一致性、每 token/每 step 成本与分布式 hang 的恢复时间；不把“CUDA 兼容”当作二元结论，而拆为 API 编译、算子正确性、性能、分布式通信、可调试性五个待验收层次。

- 一项关键自定义算子无法替代即暂停，先由供应商给修复计划；不以绕开负载的 demo 通过。
- 仅看首小时跑通不足；扩容后吞吐下降或 loss 不一致，则 MetaXLink/MXMACA 价值尚未证明。
- 曦彩 G 系列尚在研时，图形渲染不列为其交付承诺，可先用 C 系列计算负载评估数据闭环。
- 供应商拒绝提供版本支持、备件与升级边界时，不把其放入关键训练路径。

### 投资与并购

不建议以一级市场方式新增财务投资：公司已于 `2025-12-17` 上市，应按二级市场框架评估市场价格、流动性与锁定期。2025 年营收与销量是实质去风险信号，但归母净亏损仍为 `7.89 亿元`。整体并购不建议——上市主体、规模化股东与完整软硬件团队使控制权交易成本极高；可围绕机器人编译器、算子、应用支持做小型合作或人才项目，但不以并购获得训练 GPU 供应。

### 自研启示

沐曦的价值主要在训练/推理 GPU 平台，不能证明本公司应复制一颗云端 GPGPU。应将其作为“采购/合作”的高门槛参照物，比较 GPU IP、HBM、互连、编译器与生态的全栈投入；自研只有在负载足够稳定、量大、软件与供应链团队齐备、相对采购有可量化优势时才成立。云端 C500（350W 级数据中心板卡）不能直接等同为机载机器人芯片，端侧仍需独立评估低功耗边缘产品与安全架构。

## 风险、反证与未知项

- **C600 量产**：年报称 `2025` 年末风险量产、预计 `2026H1` 量产销售；“预计”不等于已规模交付，未找到逐批产量/良率披露。
- **CUDA 兼容**：公司称支持 `6000+` CUDA 应用、`1000+` 模型；兼容范围、精度、性能和特定版本不公开，不同模型/自定义算子迁移成本可能很大。
- **集群规模**：原报告称千卡商业化、推进万卡；补充报告的官网里程碑口径称 `2024 年`全年落地算力集群总规模“超过万卡”。两者的时间、累计/单项目范围和“落地”定义无法直接对齐，未披露每个集群的卡型、网络、有效 MFU 与持续运行时间。

> **Status: Disputed**
> “推进万卡”与“全年落地算力集群总规模超过万卡”来自两份本地报告的不同公司口径；前者不能被静默改写为后者。将规模作为系统交付线索，须以具名客户、拓扑、验收、利用率和回款材料复核。
- **商业化质量**：2025 营收 `16.44 亿元`、销量 >5.5 万颗，仍亏损 `7.89 亿元`；客户/订单明细因商业秘密豁免披露，难判订单质量与回款。
- **机器人适配**：年报把具身智能列为前沿布局并列出“大晓机器人开悟世界模型 3.0”适配，但未见公开、独立的实体机器人训练/部署和安全关键推理验收。
- **供应安全**：公司称 C600 基于全国产工艺并在晶圆、封测、存储、EDA、IP 环节取得突破；但“全国产工艺”范围、HBM 来源、产能与替代性能未充分公开。
