# 砺算科技（Lisuan）

> Sources: 本地横纵研究报告，2026-08-06
> Raw: [砺算科技横纵分析报告](../../raw/sources/2026-08-06-砺算科技_横纵分析报告.md)
> Updated: 2026-08-12

## Overview

砺算科技是一家由 [S3 Graphics](../institutions/S3Graphics.md) 背景团队创办、把自研图形 GPU 架构和 Windows/图形 API 兼容放在第一位的中国 GPU 公司。其首代 6nm 7G100/Lisuan eXtreme（LX）已从工程样片进入公开发售与专业卡交付验证阶段，但已公开的产品重心是图形渲染和端侧推理，不是可替代 CUDA/HBM 集群的机器人模型训练 GPU。对人形机器人公司，其价值集中在渲染/可视化、数字孪生和端边小模型推理的探索性用途，而非训练主平台。

## 业务与产品定位

- 主分类为 `1.4 图形GPU（桌面／工作站／专业可视化）`，不设置 2.1 次分类。报告指出砺算的可识别核心价值创造是自研完整 GPU 芯片和图形卡，首代商业重心明确偏图形渲染，因此 1.4 比 1.1 更准确；这不否认未来可拓展 AI 计算。
- 公司宣称自研软件栈、LSRT 推理引擎和 TVM 后端，并以 OpenCL/API 兼容提供计算能力；但当前未形成符合 2.1 要求的主流训练框架后端、广泛自定义算子、分布式通信和开发者产品体系。软件方向保留为观察项，不作为次分类。
- 公开消费卡 `LX 7G100` 为 12GB GDDR6、四个 DP 1.14a，标称支持 DX12/Vulkan 1.3/OpenGL 4.6/OpenCL 3.0、8K60 显示和 HEVC 编解码；专业系列 `LX PRO/ULTRA` 为 24GB GDDR6，ULTRA 页面标称最高 24 TFLOPS FP32 和 16 路虚拟 GPU，面向服务器/工作站、SR-IOV 虚拟化、数字孪生。
- 上市节奏（公司官方 2026 回顾，公司声明）：2025-05-24 回片、24 小时点亮、2025-07-26 发布 7G100、2025-09 完成量产片流片、2026-02 量产片回片、2026-03-12 公开发售。其"2025-07 发布"与新闻页显示 2025-08-04 的发布日期存在网页发布/活动日期差异。
- 软件方向（LSRT 推理引擎、TVM 后端扩展、NRSS 超分辨率、双发射、乱序渲染等）为公司**意图和产品接口**，不能证明其已拥有 PyTorch/CUDA 等价的训练栈、主流 transformer 算子覆盖、分布式通信或 HBM 集群能力。

## 纵向演进

- 前身主体**南京砺算科技有限公司**于 `2021-08-11` 成立；融资与经营承接主体**砺算科技（上海）有限公司**于 `2022-04-26` 成立。东芯股份投资协议明确要求南京主体将固定资产、知识产权、技术资料、员工、债务及客户/供应商关系向上海主体转移，说明后者是融资与经营承接平台。
- 联合创始人为宣以方、孔德海（DEHAI KONG）和牛一心（I-sing Roger Niu），履历共同追溯到 [S3 Graphics](../institutions/S3Graphics.md)；此类履历由公司/人物侧材料主张，宣传数字未被作为已审计事实。
- 媒体调查报道（36氪转载"电厂"，2025-05-12）称宣以方等核心团队在 S3 Graphics 之后曾任职兆芯，2018 年部分中高层离职创立中天恒星，中天恒星 2021 年资金危机后核心团队再创立砺算科技；但当事人公开履历自述（百度百科"宣以方"词条）未提及兆芯或中天恒星，两者对 1992—2021 年间的任职经历存在正面冲突，未获裁定。详见 [兆芯（Zhaoxin）](../institutions/兆芯（Zhaoxin）.md) 与 [砺算科技关键尽调问题](../questions/砺算科技关键尽调问题.md)。
- 技术路线为自研 ISA、计算核心、驱动和图形 API 兼容的 TrueGPU，先进入 PC/工作站、数字孪生、云桌面、云游戏、XR 和座舱。
- 融资（严格保留原口径）：2022-02-23 天使轮"数亿元"（达泰资本、将门创投等）；2022-10-09 Pre-A"过亿元"（君桐资本等共同领投）；2024-08—12 增资合计 `3.28 亿元`（东芯 2 亿元等，东芯投前估值 2 亿元、完成后持股约 37.88%）；2025-09—2026-01 外部投资人约 `5.00 亿元`、另员工持股平台增资 `3239.46 万元`，最终协议表列交易现金合计 `5.323946 亿元`（含员工平台），投前估值 `35 亿元`，东芯最终持股 35.87%。
- 财务承压：2024 年 L1 模拟合并财报中 2023 年无营收、净亏损 `1.45 亿元`；2024 年上半年无营收、净亏损 `9789.73 万元`，负债高于资产 `1.483 亿元`，审计报告对持续经营重大不确定性作强调；2025 年 1—7 月仍无营收、净资产为负。
- 产品延期：2022 年材料曾预期 G100 于 2023 年进入市场；直到 2024-08 创始人仍称处于 IP 集成和流片前最终验证阶段；2025-05-24/25 首批封装 G100 芯片到货并在 24 小时内完成主要功能测试"结果符合预期"，但完整功能、性能、可靠性、良率和客户导入仍未完成。
- 商业化：公司称 2026-03-17 起专业卡接受企业订单；截至研究日，未在所核验的 L1 公告中披露砺算自身具名、金额、已验收的客户订单。"接受订单"不等于"获得订单"。

## 对机器人战略的含义

### 采购与合作

可做"渲染+端侧推理"联合 POC，不做训练主平台。对机器人数字孪生、远程运维可视化、仿真工作站、边缘 VLM/VLA 小模型推理有潜在价值。用 LX PRO/ULTRA 做 60–90 天封闭 POC（数字孪生实时渲染、相机流解码、INT8/FP16 VLM 推理、容器/虚拟化、故障恢复），需与 NVIDIA/AMD/摩尔线程同一模型、数据、功耗和驱动版本做对照，并提交可重复脚本与完整日志。

### 投资与并购

投资为观察性小额/战略期权：已有一次真实 6nm 大芯片点亮、公开产品和两轮大额续资，但首代公开游戏实测低于 RTX 4060，且 2025 年 1—7 月尚无营收、净资产为负。可在现有股东/下一轮争取小额战略份额，附带测试卡、驱动路线图和联合验证权。并购暂不建议整体进行（35.87% 股权由东芯股份持有、南京砺算仍为 30.87% 大股东，全公司估值、控制权、员工激励和图形生态投入抬高复杂度）；仅评估小范围人才/软件/IP 合作或重大经营下行时的资产收购窗口。

### 自研芯片启示

砺算证明"图形 API 兼容+大芯片量产"是一条独立且昂贵的路线；其 12/24GB GDDR6 产品说明这不是机器人训练集群的 HBM/scale-up 方案。自研芯片仍应从本公司确定的机器人推理/视觉/控制负载倒推，不应复制通用消费图形 GPU 路线。

## 风险、反证与未知项

- 首代公开评测：Tom's Hardware 转引潮玩客在 9800X3D 平台、1080p 多游戏实测显示 LX 7G100 低于 RTX 4060、Arc B580、RX 6600 XT，且 `3299 元/约 485 美元`定价削弱消费者价值主张；游侠网转述 18 款游戏测试约为 RTX 3060 的三分之二；游民星空 19 款游戏评测认为 1080p 多数项目可达 60FPS。评测的游戏、画质、超分设置和驱动版本不同，不构成"谁对谁错"结论；共同高信号是首代卡已能跑现代软件，但性能和工具/驱动成熟度尚未证明可按国际同价主流卡采购。
- 公开可检索的真实开发者反馈集中于游戏与装机社区；未发现可复现的 PyTorch、TensorRT 替代、VLA/VLM 或机器人中间件长期部署评测，此缺口不能用公司"AIPC/DeepSeek 支持"宣称补上。
- 飞渡合作（"元尊 Freedo Yuan S800"空间智能一体机）是当前最接近行业工作负载验证的材料，公司称城市级 CIM 可达 RTX A5000 水准并列出 2K 58FPS、400 平方公里地形、30 万平方公里倾斜摄影等数字；但这些指标无公开测试配置、对照驱动版本、飞渡独立复现报告或采购规模，只可列为待验证的合作效果。
- 6nm 代工：产品和媒体均称 6nm，有媒体推测中芯国际代工；但砺算/东芯 L1 公告未在已核验材料中确认代工厂、封测、良率或产能，是供应安全的核心未知。
- AI 训练能力：LSRT、TVM 后端及 AIPC/本地模型为公司主张；没有公开 PyTorch 兼容性、分布式训练、通信、HBM 或机器人 VLA 基准，应明确排除其作为当前训练集群替代品。
