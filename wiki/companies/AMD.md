## Overview

AMD 以 Instinct 数据中心 GPU、ROCm 软件、EPYC CPU 与 Pensando/FPGA 资产组成对 NVIDIA 的第二平台路径。对人形机器人公司，AMD 是高端训练/推理 GPU 的双供候选，但不能假设它可单独替代所有 CUDA 负载；应以 ROCm 迁移 PoC 和双源采购验证实际迁移成本与供应条件。

## 业务与分类

- 主分类为 **`1.1 GPGPU（AI GPU）`**：报告将 Instinct 定位为数据中心 GPU，并将 GPGPU 列为 AMD 的主分类。
- 次分类为 **`2.1 加速计算平台`**：ROCm 是 AMD 的软件平台；其生态成熟度、库覆盖与客户迁移成本仍须按具体工作负载验证。
- 次分类为 **`FPGA`**：报告称 AMD 收购/整合 Xilinx 后扩展 FPGA 与自适应计算；该标签对应 Xilinx 产品线，不替代 GPGPU 主分类。

## 路线与竞争位置

AMD 从 CPU 与图形业务演进到 chiplet、EPYC 和 Instinct，并以开放软件与多产品组合争取数据中心份额。相对 NVIDIA，报告将开放性、CPU/GPU 组合与供应商多样性列为其潜在优势，同时指出 CUDA 兼容、软件工具和部分模型优化的迁移成本是短板。相对 TPU/ASIC，Instinct 更通用；相对国产方案，AMD 的供应与生态更成熟，但主权与成本未必占优。

## 机器人战略动作

- **采购/合作：**将 AMD 作为高端 GPU 双供候选，针对目标训练、推理及数据处理工作负载实施 ROCm 迁移 PoC，并以双源采购验证软件兑现、迁移成本和供应条件。
- **投资/并购：**本报告未提供可支持股权、估值、交易可行性或资产边界判断的材料，不形成投资或并购结论；先补充最新 SEC 披露、SKU 规格、第三方基准与客户验证。
- **自研启示：**EPYC、chiplet、Xilinx 与 ROCm 的历史积累显示第二平台能力依赖软硬件组合；是否可进入关键训练集群仍由软件生态兑现决定。

## 风险、反证与未知项

- ROCm 生态追赶不足是危险剧本；开放生态与 CPU/GPU 组合扩大则是乐观剧本，二者均须通过目标工作负载验证。
- 具体 Instinct SKU、ROCm 版本、模型性能、交期、价格、客户折扣和 FPGA/网络产品归属均未确认，必须按采购场景复核。
- 报告仅基于 AMD 年报、产品页和 ROCm 公开文档的已知框架；缺少最新监管披露、第三方基准与客户验证，不能将路线描述当作采购性能或交易结论。
