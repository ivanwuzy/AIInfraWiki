## Overview

算能科技（Sophgo，产品品牌“算丰 SOPHON”）是一家中国算力公司，以自研 TPU 推理处理器、RISC-V 通用处理器及其板卡、服务器和工具链为交付单元。已被验证的收入承载场景以视频智能分析和边缘/专用推理为主，而“云端大模型训推一体”是正在扩展、尚需以客户、性能和供应链证据验证的第二增长叙事。对人形机器人公司，算能是端侧多相机视觉推理、边缘数据采集筛帧和自主可控边缘系统（RISC-V＋TPU 组合）的候选节点，不是训练 GPU 的直接等价物；其价值取决于具体模型能否在真实功耗、热设计和供货条件下稳定量产，而非视频“路数”等标称宣传。

## 业务与产品定位

- 主分类为 `1.2 TPU（ASIC）`，不设置 2.1 次分类。算能官网持续以 BM1684X、BM1688 等 TPU 处理器为产品核心，并把模组、服务器、盒子及行业方案建立在这些专用推理芯片之上。BM1690 的“训推一体”宣传不改变这一主判断。
- TPU-MLIR、Sophon SDK、示例与 LLM-TPU 表明算能拥有服务芯片部署、模型转换和运行时的工具链，对客户迁移与生态有价值；但当前证据更接近专用芯片的模型转换和部署体系，尚未证明符合 2.1 所要求的通用外部扩展、训练广度和平台组件完整度。若后续形成独立算子开发、训练及多卡平台，再复核 2.1 或 2.2。
- 视频智能分析产品线标称：BM1688 为 `16 路`高清视频智能分析、`16 路`高清硬解码、`10 路`高清硬编码；BM1684X 为 `32 路`分析、`32 路`硬解、`12 路`硬编。这些是厂商标称条件而非通用模型 benchmark，不能外推成机器人 VLA token/s。
- SG2042 被官网称为“行业首款 `64 核` RISC-V 处理器”，主频 `2 GHz`、`64 MB` 共享三级缓存，并围绕它销售 SRA1-20 计算、SRB1-20 存储、SRM1-20 融合服务器及 SRC1-10 机柜级集群。它是可选边缘/专用服务器平台，不是训练 GPU 的直接等价物。

## 纵向演进

- `2016`：官网定为算丰 SOPHON 品牌问世、聚焦应用驱动算力产品；随后 `2017` 发布 BM1680、`2018` 发布 BM1682 与 BM1880。
- `2019`：官网称算能公司成立、BM1684 发布。起家路径不是训练集群，而是安防、交通、城市治理等高路数视频场景中的解码、预处理、INT8 推理、主机/模组与行业方案打包交付。
- `2020`：发布 CV183；`2021` 发布 CV182，且“算丰合并入算能，完成 A 轮融资”。A 轮金额、投资方、估值、法律主体、交割日期均未公开披露。
- `2022`：官网记为 BM1684X、CV181 与 CV180 发布及 A+ 轮完成。A+ 轮同样仅确认“完成”，未披露金额与投资方。BM1684X 仍用于模组、SE7 微服务器、SE8 服务器和多类行业一体机。
- `2023`：官网列出 BM1688、CV186 系列和 SG2042；SG2042 把 RISC-V 主机放入服务器，代表公司试图取得控制平面与通用计算生态。
- `2024`：官网称发布“大模型训推一体处理器 BM1690”；`2025` 发布第二代服务器级 RISC-V 处理器 SG2044。报告仅将 BM1690 视为已公布的产品方向，未将其算作已验证的机器人训练底座。
- `2026-01`：官网公告与清程极智签约，拟围绕云端算力、推理引擎和大模型服务平台协同，清程极智“赤兔 Chitu”将与算能芯片做算子、计算图、内存调度和部署工具链联合优化；同月也与 360 集团签署智能体生态战略合作。合作公告能证明适配意图，不能证明采购金额、推理性价比或生产 SLA。
- 软件栈：算能在 GitHub 组织公开 tpu-mlir、sophon-demo、sophon-sail、LLM-TPU 等仓库，降低了“第一天无法启动”的风险；但 GitHub 存在不等于开发者生态成熟，须按仓库核对支持矩阵、算子覆盖率、量化精度、issue 响应与许可证。

## 对机器人战略的含义

### 采购与合作

进入“工程验证＋供应链尽调”的观察池，不建议以“国产替代”标签采购。端侧推理应选计算边界清楚的任务（多相机 2D 检测/跟踪、仓内安全识别或低风险语义分割），在算能模组与 NVIDIA/地平线/通用 SoC 基线同测，指标包括精度、P50/P95 延迟、端到端功耗、冷启动、热稳态、故障恢复、模型升级耗时和单位成本，不得用视频“路数”代替机器人帧率。数据闭环可将算能定位为“数据入口的可选计算节点”。云端训练与推理应拆开招标，BM1690/SophNet 仅进入离线推理、蒸馏、量化或小规模服务 PoC。

### 投资与并购

当前为观察优先，不建议在未取得融资/股权、订单、供应与软件数据前做高溢价财务投资。融资结构未公开、客户/订单/出货量未公开、BM1690 第三方性能与生产状态不明，且供应链合规风险须独立审查。不建议以整家公司并购为默认选项：公司产品线横跨 TPU、视觉 SoC、RISC-V、整机和行业方案，整并将带来 SKU、客户支持、供应链和潜在关联方复杂度；可探索对特定软件、边缘模组团队或联合实验室的资产/人才合作，但须以清晰 IP、客户合同和出口合规审查为先决条件。

### 自研启示

算能的存在对我方最大启发是：机器人自研芯片应从确定工作负载出发（多路相机 ISP/编解码、视觉特征提取、低比特 Transformer、确定性 I/O 和安全域组合），而非先定义“做一个通用 GPU”。短期与其自研大模型训练芯片，不如先建立多供应商的模型编译/运行时抽象层，保留算能、GPU、NPU 等后端替换空间。

## 风险、反证与未知项

- 融资历史不透明：A 轮（2021）与 A+ 轮（2022）仅被官网确认轮次发生，金额、投资方、估值、股份比例、cap table、优先权、质押、关联交易、IP 归属均未公开。
- 供应与合规风险：2024 年路透社报道称，台积电在一颗芯片于华为产品中被发现后暂停对 Sophgo 的出货；报道关联与交易细节应由法律尽调和一手监管文件复核。停供一个模组会牵连整机认证和售后，不是可接受的“研发波动”。
- 大模型训推能力未验证：公开完整规格、独立 benchmark、出货和训练集群证明不足；不应把“训推一体”宣传视为已验证的机器人训练底座。
- 客户商业化：官网展示城市治理、安防、工业等场景及大量 SKU，但缺少可审计客户名单、订单、回款与复购数据；场景案例不应计为订单证据。
- 人员口径：官网两处研发/学历比例分别为“>70%/>80%”与“>73%/>78%”，统计基数、日期不同；核心创始团队履历、实际控制人与比特大陆/相关主体关系、关键架构师留存是影响供应合规、团队稳定与并购可行性的一级未确认事项。
