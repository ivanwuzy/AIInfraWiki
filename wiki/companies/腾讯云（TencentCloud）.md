## Overview

腾讯云（Tencent Cloud）是腾讯控股在云与智慧产业事业群（CSIG）框架下销售公有云资源、云原生与数据产品、行业解决方案及混元（Hunyuan）模型服务的云服务品牌。它不是可被当作单一法人的独立投资标的；对人形机器人公司，应作为中国本地算力、数据、训练/推理与远程运维底座的竞争性采购候选，而不是机器人基础模型、具身数据资产或整机能力的当然提供者。[来源：本页 Raw]

## 品牌、主体与区域边界

- **品牌不等于合同相对方：**腾讯云是品牌与业务体系。招标、订单、发票、服务协议、数据处理协议、支持单和事故通知应逐项列明实际卖方、运营方、处理方及支持方，不接受仅以“腾讯云负责”替代责任分配。[来源：本页 Raw]
- **中国法人锚点：**Tencent Cloud Computing (Beijing) Company Limited（腾讯云计算（北京）有限责任公司）被腾讯集团 2024 年报列为中国境内 `100%` 持股子公司，注册资本人民币 `10.425` 亿元，主营为信息系统集成服务；这不证明其承接全部中国 SKU、项目合同、模型 API 或其他区域订单。[来源：本页 Raw]
- **区域须逐单核验：**境外站点与跨境业务应以注册/订单页、服务协议的区域版本及订单列明的腾讯云关联方为准。北京法人、国际站可访问性或品牌页面均不能单独证明跨境数据驻留、服务责任或区域卖方。[来源：本页 Raw]
- **集团能力不外推：**腾讯的社交、游戏、投资、AI Lab、Robotics X、微信生态及被投公司能力，未取得具体 SKU、许可、数据授权、价格或项目验收证据前，不归入腾讯云可交付能力。[来源：本页 Raw]

## 产品定位与分类

- **主分类：**[8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)，高置信。报告将云服务的收入承载物界定为按订阅期或资源消耗销售的计算、存储、网络、数据库、云平台和模型服务。[来源：本页 Raw]
- **不设正式次分类：**云方内部使用容器、调度、模型运行时或多区域资源管理，不能证明其将 `3.5`、`4.1`、`4.3`、`4.4` 或 `5.1—5.5` 作为独立、可验收的主要收入承载物对外出售。[来源：本页 Raw]
- **模型服务边界：**混元通过腾讯云面向企业开放，不能据此推定客户取得模型权重、训练语料、永久输出权或指定地域调用权；这些取决于产品补充协议、控制台配置和审计结果。[来源：本页 Raw]

## 对人形机器人的采购与交易判断

| 决策 | 当前判断 | 执行条件 |
|---|---|---|
| 云采购 | 推荐进入竞争性采购。 | 与至少两家替代云就同一工作负载进行压测、三年 TCO 与数据合规评估。[来源：本页 Raw] |
| 战略合作 | 条件成立。 | 从 `90—180` 天、可验收的 POC SOW 开始，写明主体、数据、IP、SLO、价格上限、迁移和宣传权。[来源：本页 Raw] |
| 直接股权投资或控制性并购 | 不成立。 | 腾讯云是腾讯集团业务品牌；公开资料未显示独立融资、资产剥离或可收购边界。[来源：本页 Raw] |
| 自研机器人核心栈 | 应保留。 | VLA/WAM、控制、安全策略、数据集权利和评测保持供应商中立，不因采购云或模型 API 外包。[来源：本页 Raw] |

对训练、推理与数据闭环，先以隔离且可迁出的 POC 检验目标区域的实际芯片、驱动、框架、吞吐、故障恢复、队列等待、TTFT、TPOT、P95/P99、数据删除及成本；完成一次至第二云或自有环境的恢复演练，再扩大生产使用。[来源：本页 Raw]

## 冲突与关键未知

报告没有将品牌、法人和地区矛盾平均化：腾讯云计算（北京）有限责任公司是重要的中国境内法人锚点，但是否为所有中国订单的唯一卖方未确认；海外区域的签约主体、DPA 与数据驻留也未确认。腾讯云单独收入、毛利、GPU 规模、目标区域供给、可复用人形机器人订单、VLA/WAM 框架和机器人数据服务均未披露或未获得足以证明的公开一手证据。详见[腾讯云主体、区域、模型 API 与机器人交付尽调](../questions/腾讯云主体、区域、模型API与机器人交付尽调.md)。[来源：本页 Raw]
