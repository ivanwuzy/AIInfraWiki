# 超星未来（Novauto）

> Sources: 本地横纵研究报告，2026-08-10
> Raw: [超星未来横纵分析报告](../../raw/sources/2026-08-10-超星未来_横纵分析报告.md)
> Updated: 2026-08-10

## Overview

北京超星未来科技有限公司以边缘 AI NPU SoC「惊蛰 R1」、部署工具链「鲁班」及开发套件/边缘设备为公开产品承载物；报告将官网品牌、`novauto.com.cn` 与该法定主体绑定，但明确排除教育科技品牌“超星”及未证明控制、资产归属的近名主体。公司公告过与埃夫特、自变量机器人等的战略合作，但公开材料不构成机器人量产订单、收入或下一代大模型芯片已流片/量产的证据。

## 主体、产品与证据边界

- 研究对象限于**北京超星未来科技有限公司**。报告以官网产品页面、新闻 API 与官网发布的埃夫特合作公告交叉定位品牌及产品；这不证明品牌之外的近名公司、早期投资者的当前持股，或全部专利/IP 都归本主体。
- 报告记录「惊蛰 R1」为基于“平湖”NPU 的边缘侧 AI 芯片，公开页列有 `TSMC 12nm`、`16 TOPS@INT8`、CPU/NPU、内存、接口及编解码规格。该等信息支持其为边缘 NPU 候选，不支持出货量、第三方性能、车规产品认证或运行完整 VLA 的结论。
- 「鲁班」被描述为涵盖量化、编译器、runtime、Middleware、BSP、框架适配及 API 的部署工具链；公开材料缺少可取得 SDK、版本矩阵、算子清单、代码、开发者或独立运维证据，不能视为已达到 CUDA-like 加速计算平台门槛。
- 「高峡」NPU、端侧大模型与「仓颉」数据平台属于公司路线或演讲材料中的公开主张。下一代芯片的型号、流片/回片、内存带宽、功耗、测试条件、供货和客户交付均未在报告中得到独立验证。

## 商业与机器人相关性

- 公司 Pre-B 公告称 `2024` 年完成“数亿元”融资，并称 `2023` 年实现“数千万元营收”；这是公司自述的商业化线索，而非审计口径收入、回款、客户集中度或当前 cap table 证据。
- 报告记录与埃夫特的合作方向为基础感知、智能计算和数据采集管理平台；与自变量机器人的表述是共同探索端侧大模型与通用智能体研发。两者均应保留为战略/技术合作，不能升级为采购订单、量产、收入或 IP 归属。
- 对人形机器人，R1/NE101 适合在视觉感知、日志/数据治理、非安全关键轻量子模型中进行隔离式 POC；不应承担 VLA/世界模型训练主算力，也不应在首轮 POC 承载运动控制安全闭环。

## 投资、并购与采购判断

**投资：**观察池，不能以“机器人芯片龙头”逻辑定价。升级前需审计口径收入/毛利/现金消耗、下一代芯片硅后资料，以及至少一个具名机器人客户的付费部署和复购证据。

**并购：**不建议启动整体并购。若有业务需要，只考虑开发板、工具链、特定 NPU IP 或联合方案的非排他性权利；先完成主体、IP/代码/第三方组件、供应链和核心人员约束的 P0 穿透。

**采购/合作：**先索取 R1/NE101 现货、BSP/SDK、供应与 EOL/PCN 机制，按固定模型、输入、精度、温度和工作负载测试端到端延迟、能耗、稳定性、异常恢复和可维护性；未通过时仅保留技术交流。

## 分类建议

- **推荐主分类（暂定）：**[1.3 NPU（ASIC）](../segments/1.3-NPU.md)。当前客户购买的核心承载物是边缘 AI NPU SoC、模组及开发套件，且报告的现有营收表述围绕芯片和边缘方案。
- **推荐副分类：不授予正式标签。5.2 推理框架]是鲁班的条件性候选；7 数据服务是仓颉的条件性候选。两者均缺独立产品/收入/客户或开发者证据。
- **不归类：**不因机器人合作或大模型宣传进入 `6.5 VLA`、`6.6 WAM`；不进入 `2.1 加速计算平台`。仅当已验证的主要收入承载物转为独立软件或数据服务时，才重新评估主分类。

## 冲突与未确认事项

> **Status: Disputed**
> R1 的典型功耗有两个公司口径：官网产品页称约 `5.5W`，公司 `2024` 年演讲称约 `7—8W`。报告未获得相同工作负载、散热边界及芯片/板级测量条件，故不裁决；机器人 POC 应实测板级与整机功耗曲线。

- “批量落地”、乘用车上车计划及机器人合作均缺具名客户、订单、数量、验收和回款；不得作为可验证销量或收入。
- 当前股东、实控人、统一社会信用代码、历史名称、完整 cap table 与资产/IP 权属未获可复现全量档案；任何投资或并购前均为 P0 条件。
- R1/NE101 的可购性、长期软件支持、晶圆/封测/DDR 供应，及高峡的工程样片/量产状态均待核验。
