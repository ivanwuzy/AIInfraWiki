## 概览

澎峰科技的当前可验证重心是异构硬件上的计算库、算子、量化／模型转换和适配工程，而非已被证明的全栈 AI 基础设施。工商线索将品牌锚定为**澎峰（北京）科技有限公司**；官网将 `PerfXLab Technologies Co., Ltd.` 描述为市场、宣传、商务和产学研合作总部。二者尚不足以证明北京、长沙、青岛主体之间的完整股权、IP、雇佣或服务器／云合同承接关系。对人形机器人公司，它是国产／非 NVIDIA 芯片上的算子迁移 P0 候选，也是推理软件 P1 观察标的；不应仅因融资、合作或开源关联而启动投资或并购。

## 主体、产品与商业边界

- **主体事实：**36氪 PitchHub 所列工商主体为澎峰（北京）科技有限公司，法定代表人为张先轶，成立于 `2016-06-20`。报告同时记录官网关于北京总部、长沙研发主体和青岛研发中心的叙述；这些叙述不能替代各主体的股权、签约、资产和 IP 穿透。
- **公司产品陈述：**PerfMPL 被定位为面向 ARM／x86 与 NPU／GPU／DPU 等加速器的数学、DNN 和图像等计算库，官网称其有近 `6,000` 个 API；PerfXAPI 被定位为面向 ARM／x86／RISC-V CPU + xPU 的跨架构 API 模型，并提到 OpenCL、SYCL 与 ONNX Runtime。以上是公司公开产品边界与性能工程能力线索，不是全硬件、全模型或生产稳定性的证明。
- **推理与开源：**PerfXLM 是公司自述的大模型推理引擎。OpenPPL／PPLNN、PPL LLM Serving、PPQ 与 `ppl.cv` 的公开代码可见 ONNX、LLaMA serving、量化、图像处理及 CUDA/NCCL 等实现，足以支持技术候选定位；网站未直接证明这些组织、代码、商标和商业合同均由澎峰（北京）科技有限公司控制或可转让。
- **云／服务器边界：**PerfXCloud 的训练、微调、推理文案及 CT100／CI100 的服务器页面，最多支持软硬集成入口的线索。未见可验证的集群规模、调度架构、训练并行、checkpoint／弹性恢复、客户验收、订单、收入或 SLA，因此不得写作成熟云业务、分布式训练软件或自研芯片能力。
- **媒体／数据库线索：**`2016-11` 天使轮 `550 万元人民币`、`2018-06` Pre-A“千万级／千万量级人民币”和 `2024-01` A 轮“数千万人民币”均来自数据库或媒体交叉披露；估值、持股、条款、到账、累计融资、收入与现金余额未公开闭环，不能纳入估值模型或商业规模事实。

## 产业链定位

- **正式主分类：`2.2 AI算子开发、迁移与适配`（高置信）。** 客户可能购买的承重能力是把数学／DNN 库、图像前后处理、量化和模型算子移植并优化至目标 CPU + xPU；这也是公开产品与可见代码中最接近收入承载、且具技术可验证性的部分。
- **正式次分类：`5.5 推理及训练运行时优化`（C，商业化待核验）。** PerfXLM、PPLNN／Serving、量化、dynamic batching、tensor parallel 和 CUDA/NCCL 后端更符合基于存量栈的推理优化与适配；其 IP／合同归属、版本矩阵、第三方性能和生产 SLA 均未闭环，不按通用 TensorRT-like 框架处理。
- **不列入 `5.3 分布式训练工具`。** 训练／微调营销、多卡／NCCL 参数和训练服务器不等于训练并行策略、通信／检查点／弹性恢复、集群调度及对外 SDK 的可交付证据。
- **不列入 `2.1 加速计算平台（CUDA-like）`。** 现有公开资料未同时满足驱动／运行时、编译器／IR、主流框架后端、多卡通信、调试迁移工具、外部 SDK／版本支持和真实生产使用等准入硬条件。

## 投资、并购与机器人协同判断

- **采购：P0、可退出 PoC。** 在 `6—8` 周内，以一个隔离的视觉编码器 + VLA 子图、相机前处理 + ONNX 模型或端侧模型，同条件比较目标芯片原厂栈、ONNX Runtime／TensorRT（适用时）及可获得的 PerfMPL／PerfXAPI／PerfXLM。验收正确性、精度、首 token／稳态时延、吞吐、显存／内存、功耗、故障恢复、可重复构建、许可证、版本回滚及工程工时；不接入机器人实时控制或形成单一运行时依赖。
- **合作：条件性联合优化。** 仅在 PoC 达到可复现的迁移成本或性能收益，并能明确支持边界、交付物／源码权利、保密、故障响应和退出条款后，才扩展至第二芯片或第二模型。
- **投资：P1 观察。** 触发条件是取得近 `24` 个月产品化收入／毛利／续约、项目制与订阅拆分、可验证客户验收、每个硬件后端的人力成本、持续 release／维护证据，以及核心代码和商标的可处置权利。
- **并购：暂不启动。** 公开信息不足以证明核心 IP、合同、关键人才和稳定收入可随交易打包；只有 P0 证明目标芯片上的不可替代算子／编译经验，且主体、IP、团队和客户合同可转让时，才进入小范围技术／人才并购评估。
- **自研边界：**保留 VLA／VLM 模型图、数据／权重、量化验收基准、控制实时性、传感器前后处理、安全降级和多芯片抽象接口；可采购或联合开发通用 BLAS／FFT／DNN 端口、芯片后端优化和标准模型部署。
