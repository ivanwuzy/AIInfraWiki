## Overview

北京共绩科技有限公司以共绩算力、`gongjiyun.com`、`suanli.cn` 和“算了么”等入口提供 GPU 云服务。公开服务协议与裸金属条款支持其作为多来源算力聚合、容器化实例、批处理作业、大模型 API、存储与账单服务的运营／签约主体；但供应商、资源权属、跨厂商 XPU 兼容矩阵、训练或推理实测及合同化 SLO 均未公开。正式主分类为[8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)（中等置信），4.4 仅条件性观察，不纳入 4.1 跨厂商训推算力调度平台。[来源：本页 Raw]

## 主体、产品与商业边界

- **研究主体：**北京共绩科技有限公司是官网页脚和公开服务协议所示的产品运营／签约主体。共绩科技、共绩算力、`gongjiyun.com`、`suanli.cn` 可在该法人语境下视为公开品牌或服务入口；“算了么”是官网时间线列举的平台名称。股权、关联方、服务器／机房／域名／软件和商标的完整权属仍待核验。[来源：本页 Raw]
- **可确认产品形态：**弹性服务部署、Job 批处理、以 Docker 容器形式提供的云主机、整合多家优质供应商资源的裸金属、大模型 API、镜像、共享存储与对象存储加速。公开 OpenAPI 可管理服务并查询任务、节点与账单；这些能力支持“服务入口和资源聚合”的判断，而非已证实的自研调度算法或跨 XPU 控制面。[来源：本页 Raw]
- **交付与数据边界：**公开协议称云主机容器在重启、销毁或升级后，容器内部文件系统数据可能丢失。机器人数据、模型权重、训练输出和日志不得在未核验持久化、加密、备份、数据驻留与退出机制前交由其承担。[来源：本页 Raw]
- **商业与融资边界：**官网案例及降本、扩容和稳定性主张均为公司自述；没有本轮研究可验证的相对方公告、订单、验收、续费、回款或第三方压测。种子轮、天使轮及后续融资标题只能作为线索，不能累计为融资额、估值或当前股权结构。[来源：本页 Raw]

## 分类

- **主类型：**[8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)（中等置信）。服务条款关于“整合多家优质供应商的算力资源”的直接表述，以及云主机、裸金属、弹性部署、Job、账单和 API 的组合，支持其以多来源资源聚合和弹性供给服务为主要价值定位。[来源：本页 Raw]
- **条件性观察：**[3.5 调度与编排软件](../segments/3.5-调度与编排软件.md)、[3.6 集群管理软件](../segments/3.6-集群管理软件.md) 和[3.7 监控与健康管理软件](../segments/3.7-监控与健康管理软件.md)。弹性部署、自动重试、动态 GPU 分配以及任务／节点／账单查询可形成有限线索；缺少独立软件产品、架构、支持矩阵、生产客户、SLO、故障恢复和收费边界，故不设正式次分类。[来源：本页 Raw]
- **不成立：**4.1 跨厂商训推算力调度平台。公开材料未提供跨厂商芯片／驱动／框架矩阵、通信与存储路径、训练 JCT、推理 goodput／P99、精度回归、容灾记录或第三方验收；同一入口销售多来源资源不等于训练或推理任务可跨 XPU 稳定迁移。[来源：本页 Raw]

## 对人形机器人的处置

仅以非生产、可退出的第二／第三算力来源进入双／三供应商并行 PoC。以脱敏数据、可替换模型和固定视觉／VLA 微调、数据预处理及推理负载，验收实际完成作业成本、排队、Spot 中断、检查点与故障恢复、存储／数据出域、TTFT、TPOT、p95／p99、数据删除与迁出；不得将页面卡价、稳定性或案例降本数字替代验收指标。[来源：本页 Raw]

投资与整体并购均暂缓。投资前应取得完整 cap table、逐轮交易和到账材料、资源合同与转售权、背靠背 SLA、产品拆分的收入／毛利／回款、调度与运维软件 IP、数据安全记录以及机器人负载的可复现实测。若未来只需特定能力，应优先核验可转移的软件／调度团队或许可安排，而非收购尚未穿透的“云故事”。[来源：本页 Raw]

## 冲突与不确定性

公司关于机房覆盖、调度次数、稳定性、客户案例、成本与扩容的主张，均缺少本次研究获得的独立合同、验收或第三方性能材料。公开资料中“多供应商资源整合”可以支持资源池定位，但不能证明供应合同、资源资产、统一 SLA 或跨 XPU 训练／推理控制面。融资、客户、关联方与 IP 承接亦未闭环；不得将营销口径平均化为稳定商业能力。详见[共绩科技主体、供给与服务能力尽调](../questions/共绩科技主体、供给与服务能力尽调.md)。[来源：本页 Raw]
