## Overview

Groq LLC（简称 Groq）以 Language Processing Unit（LPU）专用推理硬件及其 GroqCloud 服务交付开放大语言模型的在线生成能力。其公开差异化是用编译器预先生成数据移动和执行计划，以确定性数据流服务低首 token 延迟与稳定 token 输出；这不是通用训练平台。对人形机器人公司，它是云端语言交互、远程运维和任务规划的候选推理后端，而非本体安全控制或主训练供应。

## 分类与产品边界

- **主分类：**[1.13 LPU](../segments/1.13-LPU.md)。LPU 推理硬件、系统及由其支撑的 GroqCloud 是当前技术和商业交付的核心。
- **正式次分类：无。**Groq 公开有编译器、SDK、API、文档和开发者入口，但报告未取得其覆盖训练或后训练、可扩展设备编程及完整跨负载软件栈的证据，不纳入 2.1 加速计算平台（CUDA-like）。
- 不归入 5.2 推理框架：GroqCloud 是芯片绑定的推理服务/API，不能掩盖其 LPU 硅片与系统是技术和资本密集度来源。其公开最强工作负载证据为 Llama 等开放 LLM 推理；这可作为负载关系，不能升级为公司次分类。

## 技术与交付证据

- Groq 的架构材料称，编译器在程序生成时写入数据移动计划，并把多个框架的工作负载映射到一颗或多颗 LPU；公司将这一软件优先、可编程流水线、确定性计算与网络、片上内存的组合称为 LPU 路线。
- GroqCloud、API cookbook 和 Python SDK 构成可观察的外部入口，后两者包含工具调用、RAG、批处理、MCP 以及同步/异步 REST 客户端示例。这些证据支持开发者可接入，不证明任意生产应用的兼容性、长上下文质量、峰值 p99、数据治理或迁移成本。
- 2024 年公司援引的 Artificial Analysis 测试中，Llama 2-70B API 在当时设置下为 241 tokens/s，约 100 个输出 token 的总响应时间为 0.8 秒。该结果仅限所列模型、输入输出长度与 live API 条件，不可外推为所有模型、精度、并发或总拥有成本结论。

## 商业、资本与控制权边界

- Groq 宣布的区域化交付包括与 Aramco Digital 的沙特推理数据中心、Bell AI Fabric、HUMAIN、Paytm，以及 Helsinki/Sydney 的部署和合作线索。合作、MOU、commitment 与已确认订单/收入必须分开记录。
- 2025 年 12 月，Groq 与 NVIDIA 达成非独占推理技术许可；公告称 Jonathan Ross、Sunny Madra 和其他团队成员加入 NVIDIA，Groq 继续独立运营。公开材料没有给出许可的 IP 范围、期限、费用、未来产品权利、人员数量或客户关系边界。
- 2026 年 6 月，Groq 宣布获得 6.5 亿美元 growth capital，并称运营 13 个数据中心、服务逾 500 万开发者、计划至 2027 年末接近 200MW。这些是公司披露的运营指标和规划，不是审计收入、毛利、利用率或现金流。

## 对人形机器人的动作建议

- **投资：**A 类战略观察，非优先财务投资。只有取得 NVIDIA 许可后的可转让 IP/人员边界、按区域和模型拆分的合同/续费/毛利/容量数据，并在本公司请求分布中复现端到端收益后，才进入董事会级讨论。
- **并购：**不建议整体收购。非独占许可、核心人员流动和未披露的未来技术权利使“取得决定性架构与编译器控制权”尚无证据支持；仅在可分离资产与权利被书面确认时评估小范围授权或资产交易。
- **采购/合作：**可进行 8—12 周双后端、可退出 POC，与现有 NVIDIA/AWS 后端并行测试云端语音、远程运维 Copilot、结构化任务规划和批量文本。固定模型版本、量化、上下文、采样、并发和地域，记录 time-to-first-token、inter-token latency、端到端 p50/p95/p99、成功率、重试、成本、故障切换和数据删除审计。
- **自研：**优先沉淀可移植推理控制面（路由、分层、缓存、量化、可观测性、成本归因与 fallback），不在缺少稳定大规模推理量、模型冻结窗口、编译器团队、流片/封装/供应保障和长期软件预算时自研 LPU 硅片。

## 冲突与不确定性

- 沙特 15 亿美元被公司称为 commitment，但公开资料没有合同类型、预付款、部署节奏、验收或收入确认；不得计作已实现订单收入。
- 运营规模、开发者、tokens/week 和容量扩张来自公司披露，尚无审计收入、付费转化、客户集中度、产能利用率、CAPEX、毛利或停机数据，不能据此推导盈利能力。
- 非独占 NVIDIA 许可后的 IP 范围、未来设计权利、关键人员留存和 GroqCloud 独立毛利是投资、长期采购和并购的 P0 前提；CEO 连续性亦存在 2025 年公告与 2026 年融资公告的公开口径冲突。详见 [Groq关键尽调问题](../questions/Groq关键尽调问题.md)。
