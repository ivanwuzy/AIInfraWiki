## Overview

合肥芯明智能科技有限公司（芯明）是端侧空间视觉 SoC 与 3D 视觉模组供应商。公开产品把双目深度、端侧 AI、SLAM、ISP 与相机输入集成到 NU4000／NU4100 等视觉处理器，并在 R216g 上交付近距主动双目模组。对人形机器人，其最直接的价值是手腕或末端的非安全关键近距三维感知，而非 VLA 训练、世界模型训练、全身大模型推理或安全关键运动控制。

## 主体边界与分类

- **主体边界：** 公司公告称，合肥银牛微电子有限责任公司于 2024-07-23 完成工商变更并正式更名为合肥芯明智能科技有限公司。因此，明确签约或归属于合肥银牛的历史产品与客户材料可作为当前主体的业务线索。银牛微电子（无锡）有限公司、未列明法定主体的“银牛”、以色列 Inuitive 及相关合资公司不能自动并入芯明的融资、客户、IP 或收入。
- **主分类：** 1.3 NPU（ASIC），中等置信。公开交付物是将视觉、深度、CNN、SLAM 与相机处理前置到设备端的视觉 AI SoC／模组；没有数据中心 GPU、通用大模型训练加速器或 CUDA-like 软件平台的证据。
- **不设正式次分类：** R216g 是可售视觉模组而非算力中心集成；公开材料也未见可下载通用 SDK、编译器、设备编程模型、训练框架后端、外部算子 API 或兼容矩阵，故不列入 2.1 加速计算平台。

> **Status: Disputed**
> 主体连续性仅明确覆盖“合肥银牛微电子有限责任公司”至“合肥芯明智能科技有限公司”。2023 年以“银牛微电子”名义披露的超 5 亿元 A 轮未公开完整签约主体；Inuitive 虽被官网称为子公司，但股权、专利、代码、人员及成果归属未获文件。因此，这些材料只能构成待核验的历史融资或技术来源线索，不能合成为芯明已拥有的现金、客户或 IP 资产。

## 产品与工程可验证性

| 产品 | 可由报告确认的信息 | 当前边界 |
|---|---|---|
| NU4000 | 12nm、ARM Cortex-A5、1.4 TOPS CNN、CEVA XM4 Vector DSP，覆盖 3D 深度成像、SLAM 与多路相机接口。 | 早期视觉 SoC，不是大模型训练加速器；“量产”是公司时间线口径，未见晶圆、良率或审计收入。 |
| NU4100 | 12nm、3.5 TOPS CNN、ARM Cortex-A5、深度视觉／VSLAM、ISP、六路摄像头输入及 Android/Linux/Windows 支持；转载的芯原新闻称其采用双通道 ISP IP。 | 产品与第三方 IP 关系有交叉信号，但量产规模、许可范围、持续支持及客户验收仍待核验。 |
| NU4500 | 官网当前标为“即将发布”；2024 年公告给出 12nm、8 核 CPU、最高 7.5 TOPS、10 路相机等预期规格。 | 属路线图，不计入现货、量产能力或估值增量。 |
| R216g | 近距主动双目视觉 AI 模组，推荐 0.05–0.5m，1080×720@30fps 或 544×360@60fps，平均约 3.5W、最大不超过 7W，51×41×28mm、84g，支持 GMSL 2.0 与 IP54。 | 是最适合人形手腕／灵巧手 PoC 的可安装部件；全部性能参数为公司口径，须在我方场景复测。 |

2026 年 WAIC 展示中，公司称 R 系列适配 NVIDIA AGX 与 RK3588，并展示端侧姿态／分割及 3D 虚拟安全区。这是主机接入路径的证据，不等同于得到平台厂商认证，亦不表明芯明可替代主控计算平台。

## 商业化、合作与资本

- 公司公告称 2024 年合肥银牛的双目视觉方案被小米 CyberDog 系列采用；该信息可作为具名机器人客户线索，但尚无小米反向确认、SKU、采购数量、验收、收入或持续供货证据。
- 公司曾称签约或上机测试客户超过 150 家，并列出小米、极智嘉与 Varjo 等“深度合作客户”。测试、签约、设计导入、批量交付、回款和复购必须分开验证。
- 芯明以当前主体名义公告 2025 年完成“数亿元”A+ 轮，开远实业领投，合肥产投与肥西产投跟投；公告所述银行“数亿元”授信不得与股权融资相加。估值、交割、持股、优先权、董事席位与现金余额未公开。
- 与华西医院、钧舵机器人、美团低空相关场景的公开材料说明公司在医疗配送、具身末端感知及无人机场景进行合作或探索，均不能直接推定为芯片订单、医疗合规、共同 IP 或量产收入。

## 对人形机器人的行动建议

| 动作 | 当前判断 | 前置条件或触发条件 |
|---|---|---|
| 非排他产品 PoC | 建议，高优先级。 | 取得可追溯的 R216g 样品、机械图、供电与接口文档、标定文件和驱动；在手腕／末端真实安装条件下测试。 |
| 小批量采购或联合开发 | 仅在 PoC 达标后。 | 在透明、反光、黑色物、遮挡、暗光、逆光、热、振动与多批次条件下，验证深度误差、掉帧、端到端时延、重复定位与故障恢复；明确 RMA、交期、MOQ、三年供货与 SLA。 |
| 战略投资 | 谨慎观察。 | 完成 cap table、历史融资主体、Inuitive 与芯原授权、产品／代码／专利权属、非关联客户订单与回款、量产良率及供应链 DD；PoC 证明其对抓取成功率或系统成本有可重复增益后，才讨论小比例、里程碑式选择权。 |
| 控股并购 | 当前不建议启动。 | 所购主体必须持有可转让的产品 IP、关键软件、核心人员与客户合同，并完成跨境、出口管制、许可可转让性及供应连续性审查。 |
| 自研芯片协同 | 可作技术交流，不复制其完整路线。 | 聚焦传感器端带宽、时延、标定、几何预处理与主控接口；保留独立安全 MCU／主控降级路径。 |

## 风险、反证与开放问题

- R216g 的近距、重量、功耗与接口显示其具有机器人手眼感知的产品定义，但独立抓取成功率、长期可靠性、热漂、EMI、批次一致性及量产客户均未公开。
- 芯明没有公开 ROS2、驱动、时间同步、标定、日志、版本矩阵与 SLA 等完整工程证据；与公开 SDK、文档和社区入口更成熟的 3D 相机／边缘视觉方案相比，集成与维护成本尚未证实。
- 芯原 ISP IP 的授权对象、期限、地域／工艺范围、费用、续期、可转让性及后续产品覆盖关系尚未知；Inuitive 的子公司关系也需以股权和 IP 文件核验。
- 在上述问题关闭前，视觉失效不得直连危险运动，且不得将品牌级融资、客户名称或场景合作写成审计收入、量产订单、可转让资产或安全认证。
