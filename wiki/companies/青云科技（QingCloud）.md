## 概览

本页唯一研究对象为**北京青云科技股份有限公司**（A 股 688316；报告指出其 2025 年年报披露名称为“青云科技集团股份有限公司”）。其可验证的收入承载物有两条：向企业交付软件、软硬一体机及实施维保的云产品，以及按服务期或资源用量确认的公有云与 AI 算力云服务。KubeSphere 企业版、QKE 和 Coreshub 共同构成其 Kubernetes 控制面、企业云交付和部分 AI 资源服务的产品组合；不能把这一组合写成缩小版超大公有云、跨厂商训练平台或完整训练框架。

## 主体、产品与商业化边界

- **唯一主体：**本页不把北京优帆科技有限公司的历史前身、红筹/VIE 架构下主体、北京青云智算或品牌/开源社区自动并入当前上市公司可直接交易的资产包；它们的控制、合同、知识产权与责任承接须逐项核验。
- **客户购买物：**云产品可以是软件、软硬一体化产品和售后服务；云服务可以是包年包月订阅、按实际用量计费的资源服务，以及线下签约的 AI 算力云。产品功能、官网案例、模型上架、GPU 到货、合作签约或客户预付款均不自动等于收入、订单或可用产能。
- **已确认与未确认：**报告可支持 AI 算力云已产生收入并改善云服务组合，也支持企业版 KubeSphere、LuBan、Marketplace 和 QKE 的商业化使用。报告没有公开客户名称、GPU SKU/供给、实际集群规模、KubeSphere 付费收入、模型 API 用量，或开源版与企业版的完整代码和许可证边界。
- **资本与连续性：**GPU 服务器融资租赁、应收款/收益权质押及青云智算的外部增资均须与上市公司股权融资、可支配现金和服务连续性区分；生产合同不能仅依赖销售承诺。

## 产业链分类

- **正式主分类：**[3.6 集群管理软件](../segments/3.6-集群管理软件.md)（中高置信）。KubeSphere 企业版/QKE 的 Kubernetes 多集群、租户、应用生命周期、混合环境治理与控制面是最具差异化、且有独立产品化证据的交付物。
- **正式次分类：**[3.4 容器化软件](../segments/3.4-容器化软件.md)、[3.5 调度与编排软件](../segments/3.5-调度与编排软件.md)（均为中等置信）。依据是 Kubernetes 容器平台、应用生命周期、容器云交付、应用分发、GPU 资源调度和多集群部署等已发布能力；公开资料没有按这些功能拆分收入，故仅作次类。
- **不列入：**3.7 监控与健康管理软件、2.1 加速计算平台（CUDA-like）、4.1 跨厂商训推算力调度平台和 4.4 多来源算力资源池化与控制面。监控/可观测不是已验证的独立核心收入承载；适配昇腾 NPU、海光 DCU 或跨云/跨芯叙事也不足以证明自有芯片软件栈、可验证的跨厂商训推产品、客户、性能和收入。

## 采购、投资、并购与自研判断

| 选项 | 当前判断 | 上调或继续条件 |
|---|---|---|
| 采购/合作 | 可在私有/混合云控制面和小规模 GPU 项目中做非排他、可退出的 PoC；不以模型上架替代验收。 | 在统一容器、模型、数据、节点数和网络策略下，完成 GPU/异构隔离、调度/重调度、存储、故障恢复、迁移、审计、数据删除与成本测试。 |
| 投资 | 不以持有上市公司股权换取 GPU 容量、企业版源码权或支持响应。 | 合同明确容量、授权、支持、SLA 与退出权；若评估青云智算，须穿透 GPU 资产、融资租赁/质押、应收款、客户与极端情景下的连续性。 |
| 并购 | 不建议以整体收购取得 Kubernetes 能力。 | 仅在企业版模块、实施能力或关键团队的权属、开源许可证、员工发明和客户合同均可交割时，再评估更窄的资产或合作交易。 |
| 自研 | 不重造完整云；保留 Kubernetes/Slurm 工作负载模板、镜像与驱动 SBOM、数据/检查点、评测、权限、成本归因和灾备脚本的自控。 | 外部平台不得锁定数据出口、运维接口、调度策略或关键生产控制面。 |

## 冲突与不确定性

| 事项 | 支持与限制 | 当前处理 |
|---|---|---|
| KubeSphere v4.2 状态 | 年报称 2025 年发布 v4.2/4.2.1；公开 GitHub 主仓库可见最新稳定 release 为 v4.1.3（2025-03）。 | 不裁决版本归属；索取企业版/分支版本矩阵、代码仓、许可证和升级说明。 |
| AI 算力云的业务地位 | 报告支持其作为云服务盈利改善的重要单元，但并非全公司唯一或已证实的主收入来源。 | 索取 SKU、区域、客户分层、订单/验收/回款和单位经济；不以其存在推定可用容量或最低算力价格。 |
| 异构能力 | 产品材料称可纳管/适配部分 GPU、vGPU、vNPU、vDCU、昇腾 NPU 和海光 DCU。 | 只作为 PoC 假设；逐一验证驱动、框架、数值、隔离、回滚、SLA 与故障处置，不能作为 4.1/4.4 结论。 |
