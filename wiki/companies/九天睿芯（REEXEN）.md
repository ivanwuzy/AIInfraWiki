## Overview

九天睿芯（REEXEN）是**深圳市九天睿芯科技有限公司**的品牌。该公司公开展示以 SRAM-CIM 为计算层、结合 NAND/DRAM 垂直堆叠及多层级存算融合的 AI 推理产品叙事，包括 ADA300、ADA400、HBF SSD 和 AI 推理服务器。对人形机器人公司，其合理定位是固定视觉、语音或传感子模型的端侧/端云推理 POC 候选；现有公开资料不足以证明其可承担训练主算力、生产 VLA 主推理或安全关键控制路径。

## 实体、产品与分类边界

- 本页唯一研究主体为**深圳市九天睿芯科技有限公司**；九天睿芯、REEXEN 与 Reexen Technology 是该主体在本报告证据范围内的品牌/名称表达。该映射不替代对工商股权、历史近名主体、核心 IP 或客户合同的穿透核验。
- 主二级分类为 **`1.6 存算一体/近存计算芯片（CIM/PIM）`**，中等置信。当前最明确的客户购买对象叙事是 SRAM-CIM、计算型近存/Chiplet 推理硬件及其板卡/系统，而非单纯存储容量或通用 GPU。
- 不归入 `1.7 HBM`：公司称 HBF 为 High-Bandwidth Flash/高带宽固态存储，不能与 HBM 混同。也不设 `2.1 加速计算平台` 次分类：报告未见可确认的完整 SDK、编译器/框架后端、开发者产品化和真实外部部署证据。
- ADA100/ADA200 是历史感存算路线线索；官网当前展示 ADA300N（面向紧凑边缘视觉、语音和传感推理）、ADA300D（面向 Attention 与热 KV Cache 的端云协同/云端生成式推理）、ADA400-DN-BOARD、HBF SSD 与 AI 推理服务器。产品名称和公司定位可确认；可订购 SKU、数据表、样片、软件、供货、客户验收及生命周期均未获公开闭环。

## 纵向演进与商业线索

- 报告记录公司在 **2018** 年从神经拟态感存算一体切入，后将路线从感知/低功耗入口扩展至 SRAM-CIM、NAND/DRAM 垂直堆叠、KV Cache 与 Chiplet 的多层级存算融合。这是一条技术叙事的连续性线索，不构成性能、量产或收入证明。
- 媒体报道记录 **2021-06-25** A 轮“亿元级”、**2025-09-24** B 轮“超亿元人民币”及 **2026-01-13** B+ 轮融资事件。报告保留这些为 L3 融资线索；金额、估值、比例、交割、累计融资和完整 cap table 均未公开闭环。
- “多家量产”“国际品牌订单”及 IP 授权合作出自公司披露或媒体转述。没有命名客户、SKU、验收、出货、复购或回款材料时，不把它们写作已验证的商业化、收入或长期供货能力。

## 对机器人战略的含义

### 采购与合作

仅从非安全关键、可回退的固定模型 POC 开始，例如室内视觉检测、语音唤醒/指令前处理、传感融合分类，或端云协同中缓存受限的优化环节。以相同输入、精度、batch、温度和网络条件，与既有 NPU/GPU/CPU 路径比较端到端时延、准确率、功耗、热稳定、模型转换、日志、升级/回滚与故障恢复。样片/板卡、支持模型清单、SDK、调试责任、软件许可和数据安全安排应是 POC 的前置交付物。

不要将 ADA 路线列入机器人训练主链、生产 VLA 唯一推理芯片或关节实时控制安全路径。多层级存算融合的价值须通过真实模型的准确率、尾时延、能耗、可用容量和长期稳定性证明，不能以容量、峰值带宽或“万亿级模型推理”的产品定位代替系统验收。

### 投资、并购与自研

- **战略投资：验证期权。** 以主体/cap table/IP 的法律穿透、芯片/封装/SDK/样片与供应链材料、以及指定机器人模型的真实 PPA、客户验收和回款等证据分阶段解锁投资或追加条件。
- **控制权并购：暂不建议。** 核心 IP/版图、工艺 know-how、代工封测与 3D 堆叠供应链、软件著作权、客户合同和员工权利尚未公开闭环；先做合作、少数股权或下一代产品共同定义更可逆。
- **自研启示：先锁定负载。** 如果 POC 证明固定感知或缓存受限推理存在可复现优势，可讨论特定加速器/数据路径的共同定义；这不构成复制其多层级存算路线或替换训练 GPU 的依据。

## 风险、反证与未知项

- SRAM-CIM、NAND/DRAM 垂直堆叠和 3D 互联的公开信息主要为公司技术自述；制程、精度、带宽、PVT/良率、热设计、可靠性和端到端 PPA 未获独立验证。
- HBF SSD、ADA 板卡与 AI Server 的系统产品边界未公开闭合。没有规格、BOM、软件接口、可用容量、互联、服务责任和客户验收，不能将展示页认定为可规模采购的系统产品。
- 制造、封测、存储、交期、PCN、RMA、第二来源及知识产权归属均影响机器人量产导入资格；“国产”或获得融资不等于供应安全。
