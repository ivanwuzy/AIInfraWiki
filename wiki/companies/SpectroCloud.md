## Overview

Spectro Cloud, Inc. 的 Palette／PaletteAI 是面向多云、数据中心和边缘环境的 Kubernetes 集群舰队生命周期控制面：以 Profile 把 OS、Kubernetes、网络、存储、GPU 插件及应用配置为可复用单元，覆盖部署、升级、恢复、治理和断网场景。其可验证定位是集群管理软件，而非训练／推理引擎、跨 XPU 运行时或芯片供应商。对人形机器人公司，适合作为中心云—工厂—现场边缘的可退出采购 PoC 候选；不宜据此直接启动整体并购或把厂商性能主张计为采购保证。[来源：本页 Raw]

## 主体、产品与商业边界

报告以 Spectro Cloud, Inc. 为主体；Palette、PaletteAI 与 Inference Launchpad 是产品名。Palette 管理新建或既有 Kubernetes 环境的完整生命周期，并基于 CNCF Cluster API 与 Cluster Profiles 支持跨云、数据中心、bare metal 和边缘的全栈配置复用。官网还主张 SaaS、self-hosted、air-gapped／DDIL 等交付形态及 SENA 分散式架构；这些支持其多站点管理定位，但不能证明所有硬件、驱动、网络断连方式都已生产认证。[来源：本页 Raw]

PaletteAI 将 GPU、模型和本地推理纳入既有基础设施管理层，公开强调 NVIDIA／AMD 堆栈、GPU 租户与治理、token 成本控制及 AI factory 启动方案。该产品边界仍是管理／集成层：公开材料不能证明其具备自研推理 kernel、基础模型、跨 XPU 动态路由或多厂商算力采购结算能力。[来源：本页 Raw]

2026-07-15，公司公告超过 1 亿美元的 Series D，并称累计融资 2.6 亿美元；公告列出领投方、战略参与者和多家客户名称。该材料可确认该轮公开融资、产品与客户关系线索，但未披露估值、完整 cap table、客户合同、回款、续费、毛利或 AI 产品收入占比。[来源：本页 Raw]

## 机器人战略与行动

- **采购/合作：** 先在中心云、研发实验室和模拟工厂／现场边缘节点开展 90 天、非安全关键 PoC，验证同一 Profile 的升级、金丝雀、回滚、断网恢复、GPU／NPU 驱动兼容、权限、日志和数据删除；与原生 Kubernetes、现有 MDM／边缘平台比较 SRE 人天、停机、成本及退出能力。
- **投资：** 维持 P1 战略观察。公开融资和企业／公部门案例是正面信号；应待 AI SKU、付费采用、续费、毛利、支持成本及境内交付边界被证实后，再考虑少数战略投资。
- **并购：** 不启动整体并购。Series D 后估值、现行股权、收入／毛利、专有与开源组件边界，以及 AI 商业化均未充分公开；只有 PoC 证明边缘 fleet 管理不可替代且权利边界可获得时才重评。
- **自研边界：** 保持设备身份／安全策略、模型包格式、发布审批、回滚判定和跨供应商 observability 的自主控制；可采购集群 Blueprint、离线升级、审计与模型发布接口，而不以 PaletteAI 代替 VLA 训练或推理运行时。

## 风险、反证与未知项

产品叙事越深入 OS、GPU 和边缘设备，版本耦合、资源开销、断网恢复和供应商锁定的风险越高；云厂商、原生 Kubernetes 及边缘平台亦可能覆盖部分功能。官网“70% 更高 GPU 利用率”“Token 成本下降 70%”“30 天从装机到生产”、客户案例和战略投资者均是公司或案例口径，不能外推为独立性能审计、客户收入、排他供给或普适收益。[来源：本页 Raw]

> **Status: Disputed**
> PaletteAI 的公开材料支持其将 GPU、模型与推理服务纳入 Kubernetes 全栈管理；但缺少完整支持矩阵、工作负载实测与商业产品收入拆分，因此不支持将其归为推理框架、推理 PD 分离、跨 XPU 调度或多来源算力资源池化与控制面。[来源：本页 Raw]

核心验证事项包括：air-gapped 站点的恢复和资源开销，GPU／NPU 与模型／区域支持矩阵，Profile／控制器的开源与 IP 边界，客户合同和续费，AI SKU 的付费采用，以及资本和控制权。详见 [Spectro Cloud关键尽调问题](../questions/SpectroCloud关键尽调问题.md)。

## 分类

- 主类型：[3.6 集群管理软件](../segments/3.6-集群管理软件.md)（较高置信）：核心交付是跨环境 Kubernetes 集群的全生命周期、治理和 fleet control plane。
- 次类型：[3.4 容器化软件](../segments/3.4-容器化软件.md)（中等置信）：Profile 管理 Kubernetes 全栈部署及容器应用所依赖的网络、存储和附加服务；公司并非以独立容器运行时或 Kubernetes 发行版为主要价值承载。
- 次类型：[3.5 调度与编排软件](../segments/3.5-调度与编排软件.md)（中等—较高置信）：声明式 Profile、跨环境编排、多租户、配额、升级与恢复是基础设施生命周期编排，而非训练作业调度或跨 XPU 推理路由。
