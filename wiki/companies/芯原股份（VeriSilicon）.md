## 概览

本页唯一研究对象是芯原微电子（上海）股份有限公司（科创板 `688521.SH`，品牌/英文名 `VeriSilicon`）。它以 Silicon Platform as a Service（SiPaaS）交付处理器、接口与模拟 IP 的授权，以及 SoC 架构、实现、验证和量产导入服务；客户最终销售的是其自行定义的芯片、模组或终端。Vivante NPU 是公司 IP 组合中的一项处理器 IP，不是芯原自行量产销售的标准 NPU 芯片。对于人形机器人，芯原可作为稳定边缘感知/视频 SoC 的上游项目型伙伴，不应被写成可直接替代 Jetson、昇腾或地平线的 VLA 主推理平台。

## 主体、交付物与商业边界

- 报告将上市主体限定为芯原微电子（上海）股份有限公司；`Vivante` 是其于 `2016` 年收购图芯美国后纳入的 GPU/IP 路线名称，不能独立并入其他近名主体。
- 客户购买的经济单元包括：(1) NPU、GPU、ISP、VPU、DSP、接口与模拟 IP 的 RTL/相关软件、许可范围和支持；(2) SoC 架构、实现、验证、流片/封装导入和项目管理；(3) 用于早期验证的参考平台或验证芯片。IP 授权、项目服务和客户芯片出货不可互相替代。
- 公司称采用其 NPU IP 的 AI 类客户芯片累计出货“近 `2 亿颗`”、内置其 GPU IP 的客户芯片累计出货“超 `20 亿颗`”；这是客户芯片承载其 IP 的公司口径，不是芯原标准芯片出货、IP 许可收入、机器人收入或单一客户的订单/回款证明。
- Vivante NPU 页面列出 `VIP9000` 的 `0.5—20 TOPS` 与 `VIP9400` 的最高 `80 TOPS` 公司标称范围，并列 OpenCL、OpenVX、OpenCV、Android NN HAL、TIM-VX 及 TensorFlow、PyTorch、ONNX、TVM 等 API/框架适配。没有统一且可独立复现的目标模型、精度、频率、工艺、功耗、带宽或价格资料，故不得与成品 SoC/GPU 的峰值指标直接横比。

## 产业链分类建议

- **正式主分类：**[1.3 NPU（ASIC）](../segments/1.3-NPU.md)。此处归类的是公司已经产品化、可被客户采购并进入 AI SoC 的 NPU IP 及相关 SiPaaS 交付；标签不表示芯原出售标准 NPU ASIC，也不替代其 IP 授权与定制服务的收入边界。
- **正式次分类：无。**不列 2.1 加速计算平台（CUDA-like）：公开材料只足以证明受许可的 NPU API、框架适配和 IDE 入口，尚未闭环证明跨代运行时、编译器/IR、外部自定义设备编程/算子、加速库、多芯片通信、调试迁移工具和可复现外部开发者产品化。不列 1.4 图形GPU（桌面／工作站／专业可视化）：Vivante GPU 是客户 SoC 可集成的 IP，并无证据显示公司的主收入承载物是桌面、工作站或专业图形成品 GPU。

## 对机器人战略的含义

### 采购与合作

建议仅做非排他、可退出的两阶段合作。第一阶段为 `6—10 周` 架构/软件 PoC，选择模型稳定且非安全关键的两/四路相机采集与 ISP、检测/分割、视频编码或遥操作前处理；以同一目标 NPU IP、工艺假设、存储配置、频率与工具版本，验证指定 ONNX/PyTorch 模型的算子覆盖、精度、端到端时延、峰值/平均功耗、带宽、热约束、日志和故障恢复。第二阶段仅在 PoC 达标后讨论 IP 授权与 SoC 定制，并将授权实体/地域/工艺/产品范围、NRE/royalty、交付物、缺陷修复、版本支持、第三方 IP/EDA/代工限制、流片/封测/良率责任、PCN、生命周期、RMA、数据与保密边界写入合同。

适合通过芯原或同类伙伴采购的范围是成熟 NPU、ISP/VPU、通用接口、基础 IP 与 SoC 实现服务；更应保留自研或系统控制权的范围是多传感器时间同步、确定性实时网络与安全岛、关节/末端故障降级及机器人数据采集/模型切分。快速迭代的 VLA 主模型、训练与通用推理工具链，在模型、算子、精度和生命周期稳定前应保持于可替换的平台。

### 投资与并购

不建议为获取“机器人主算力”而做大额战略入股，也不建议发起控股并购。公司是业务覆盖大量非机器人客户、第三方许可和项目合同的科创板上市主体；公开资料没有机器人客户/收入拆分、目标模型独立性能、IP 可转让性、NRE/版税、流片良率或目标项目供货责任的闭环。只有出现权属清晰、人员可承接、不受客户排他及第三方限制、并与机器人安全/视觉/实时 I/O 强耦合的独立资产包时，才进入资产级收购初筛。

## 反证、风险与开放尽调

- Coral NPU 的公开状态是与 Google 联合推出开源 IP，芯原称计划提供商业企业版且验证芯片仍在开发；这不是量产机器人 NPU、现成 VLA 主控或客户交付证明。
- 公司公开的“`1,600+`”与“`1,700+`”IP 总数来自不同时间/页面口径，均不是逐项可转让资产账册。交易不能据该总数估值或假定全部自有、silicon-proven、可再许可。
- IP/项目交付的价值高度依赖目标工艺、PDK/EDA、第三方许可、SDK、支持年限、客户隔离义务、PPA、流片与量产责任。公开产品/联盟/生态/客户芯片累计出货均不能替代这些项目级文件。
