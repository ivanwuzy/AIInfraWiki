## Overview

星宇智算（StarverseAI）是以 `starverse-ai.com` 展示 GPU 实例、模型 API、公共资源和生成式 AI 应用的品牌/项目线索。公开网页与第三方目录均不能将候选法人“厦门星宇智算智能科技有限公司”、域名、备案、平台账户、合同收款与模型/IP 归属闭合为同一责任主体。因此，本页只记录可观察的产品入口，不将其写成已验证的云服务公司、资源所有者、模型研发方、客户供应商或投资标的。[来源：本页 Raw]

## 主体与产品边界

- **品牌入口：**官网页面、邮箱和页脚共同使用“星宇智算 - StarverseAI”及 `starverse-ai.com`；网站展示 GPU 算力、AI 应用、星桥 API 与公共资源入口。[来源：本页 Raw]
- **候选法人不作确认：**“厦门星宇智算智能科技有限公司”仅是第三方企业目录所见的同名候选。报告未取得统一社会信用代码、工商档案、ICP备案查询回执、域名注册人或合同主体同一性文件，不能将站点、融资、团队、客户、资产或债务归入该法人。[来源：本页 Raw]
- **展示不等于交付：**GPU 页显示镜像、WebUI、SSH、JupyterLab 等使用方式，公共资源页列出开源模型/数据资源，资讯页展示 HappyHorse、Vera 与 AIGC 应用内容；这些均为官网自述，未证明资源自有、实际库存、价格、SLA、客户规模、模型权属或独立性能。[来源：本页 Raw]
- **关系不作外推：**页面出现的开源模型、第三方模型名或应用目录不构成联合研发、商业授权、云资源供给、数据共享或客户关系。[来源：本页 Raw]

## 分类与成熟度

- **正式主分类：**[8 其他](../segments/8-其他.md)（低置信）；不设正式次分类。现有材料没有确认唯一责任主体名下的客户购买物、合同、计量、收款、资源产权或可验收交付。[来源：本页 Raw]
- **不进入 8.1：**尽管网站展示 GPU 租用和模型 API，尚不能证明它们由唯一法人签约、交付和承担 SLA，故不归入正式 [8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)。若未来取得法人=备案=域名/平台运营者=合同/收款主体的闭环，并验证实例或 API 收入，再重新评估。[来源：本页 Raw]
- **不作模型或软件分类：**HappyHorse、Vera、“星桥 API”、开源模型目录和应用市场均未形成可验证的自研 IP、版本化运行时、独立 SKU 或客户验收，不能归入推理框架、调度、数据服务或模型类型。[来源：本页 Raw]

| 决策 | 当前建议 | 前置条件与边界 |

| 采购/合作 | 仅可考虑隔离、可退出的非关键 PoC。 | 不上传机器人真实数据、不接入生产账号、不预付；验收实际 GPU/显存/驱动、网络和磁盘性能、连续 7 天可用率、容器迁移、API P95、账单、数据删除和故障响应。 |

| 并购 | 不启动意向报价。 | 须逐项锁定法人、域名、代码、商标、模型/IP、GPU 租约、客户合同和团队的可转让性；品牌流量不能代替资产清单。 |
