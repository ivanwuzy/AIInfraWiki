## Overview

本页唯一研究对象为**北京潞晨科技有限公司**。Luchen、LuchenTech、HPC-AI、HPC-AI Cloud、潞晨云、GitHub 组织 `hpcaitech`、Colossal-AI 与 Open-Sora 仅作为品牌、公共项目或待核验关联主体处理。公开官网的结构化信息写明新加坡 **HPC AI TECHNOLOGY PTE. LTD.**，而非北京潞晨；因此，现有材料不能证明北京潞晨承接云资源、软件 IP、客户合同或收入。对人形机器人公司，它至多是可隔离验证的训练／推理工程与 GPU 云服务线索，不能据开源、基准、生态或产品入口推导订单、收入、GPU 供货、独占 IP 或可并购的完整资产包。

## 主体、产品与商业边界

- **唯一主体：**北京潞晨科技有限公司是本报告指定对象；创始团队、成立日期、注册资本和控制关系未取得可复现的一手工商材料。HPC AI TECHNOLOGY PTE. LTD. 是官网显示的另一新加坡法人，二者的控制、许可、销售与数据跨境关系均待核验。
- **公共技术与产品主张：**Colossal-AI 的论文、代码与文档可支持其分布式训练／推理工程能力的公共可见性；官网和文档还展示 GPU 租赁、镜像、模型 API 与微调服务。它们不能证明北京潞晨拥有全部著作权、专利、商标、模型权重或商业版代码。
- **客户购买物、收入承载与交付：**从外部可见的产品入口看，潜在购买物是 GPU 租赁、预配置镜像、模型 API、微调或工程支持；但未取得北京潞晨作为开票／签约／交付主体的客户合同、验收、回款、SLA、实际库存或审计资料。因此这些是关联品牌的可售主张，不是目标法人的已验证交付或收入。

## 产业链分类

- **正式主分类建议：**`8 其他`；**正式次分类：无**。目标法人、客户购买物、收入承载和已验证交付未在同一北京主体上闭环，不能以公共代码、性能自测、云入口或关联品牌替代商业承接证据。
- **条件性观察：**若北京潞晨能以合同、开票、资源权属和验收证明其实际承接潞晨云 GPU 资源交付，再调整为主类 [8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)。若能证明其只承接可交易的软件研发与持续支持，则评估 5.3 分布式训练工具 或 5.5 推理及训练运行时优化；现有材料不支持正式分类。
- **不纳入：**不因 NVIDIA GPU、NVLink、InfiniBand 的产品展示归入芯片或互联供应；不因 Colossal-AI、Open-Sora 或开源论文归入已验证软件收入、独占 IP、跨厂商调度平台或生产级机器人基础设施。

## 机器人基础设施行动判断

| 选项 | 当前建议 | 上调条件 |
|---|---|---|
| 采购／合作 | 可在公开数据、消融实验或峰值算力场景做隔离、非排他、可迁移的 POC；不得作为生产单一来源。 | 在目标 GPU、网络与数据权限下，以同一 VLA／视频模型比较 Colossal-AI、PyTorch FSDP 与 DeepSpeed 的吞吐、失败恢复、调试时间、总成本和权重迁出。合同应明确数据驻留、权重可迁出、SLA、故障补偿与计费口径。 |
| 战略投资 | 仅保留观察，不做估值或融资归属判断。 | 北京潞晨与新加坡主体的股权、IP、客户合同、财务和关联交易完成穿透；取得连续两个季度可审计收入、付费客户复购、跨 GPU 迁移实测与核心开源贡献者留存材料。 |
| 整体并购 | 当前不建议。 | 仅审查可独立交割的训练／推理软件团队或国内业务资产，并确认源代码、商标、开源许可证、模型权重、客户合同、债务、云资源承诺和数据处理责任。 |
| 自研边界 | 不自研通用分布式训练框架。 | 自主控制机器人数据治理、VLA 评测、动作安全和端云协同；采用可替换接口，避免把数据、权重或关键业务凭据锁入主体与 IP 未闭环的服务。 |

## 下一步验证

1. 核验北京潞晨的工商连续性、当前股权、控制人、关联方清单，以及其与新加坡主体、域名和品牌的许可／合同承接链。
2. 逐项确认 Colossal-AI、Open-Sora、Colossal-Inference、商业代码、模型权重、商标及贡献者劳动成果的权属、开源义务和可转让性。
3. 抽检合同、发票、验收、回款、客户复购、SLA、GPU 资源权属、机房／电力和故障记录，区分产品展示、采购、生产交付与收入。
4. 在真实机器人训练、视频与推理负载上完成性能、故障恢复、数据驻留、加密、删除和迁移出口测试。
