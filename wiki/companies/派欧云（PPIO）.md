# 派欧云（PPIO）

## 概览

本页只编译研究截止日为 2026-08-11 的本地报告。派欧云计算（上海）有限公司是本页研究主体；报告将 PPLabs Technology Limited（派想未来）列作 PPIO 的境外上市主体，但两者之间的完整协议、控制和资产承接尚未闭环。PPIO 的公开交付物是边缘云、GPU 容器、Serverless GPU、模型 API 与 Agent/沙箱等按量服务；因此，当前应将其视为分布式边缘云、GPU 云与 AI 云服务商，而非已被证明的跨厂商 XPU 统一算力控制面。

## 主体、产品与收入承载边界

- 报告记录 PPIO 由姚欣与王闻宇于 2018 年共同创立，并把其早期路线描述为分布式边缘云供给；这不能单独证明现时股权、控制比例或全部知识产权归属。
- 客户公开购买的是 GPU 容器实例、按量或抢占式容量、Serverless GPU、模型 API 和 Agent/沙箱服务。资源接入、调度、容器和弹性伸缩在当前证据中是服务交付能力，不是独立售卖的软件许可证。
- 媒体转述的申请材料称 2025 年边缘云收入占 84.5%，AI 云收入占 15.5%。该口径支持“边缘云为主、AI 云扩张中”，但不应外推为 AI 云已占主业或已盈利。

## 商业与技术证据边界

- 报告援引的媒体转述显示 2023—2025 年总收入分别为 3.584、5.580、7.703 亿元，整体毛利率由 17.7% 降至 9.4%，前五客户收入占比为 79.0%。这些是二手招股书转述，不替代原始招股书、审计报表或客户合同。
- 报告的公开产品证据可确认 NVIDIA H200、H100、H20、RTX 4090 等 GPU 容器 SKU，以及按量和抢占式购买入口；不能据此认定 GPU 为自有资产、容量充足、训练 SLA 已验证，或存在跨 XPU 统一资源池。
- “异构资源池/统一调度”的媒体转述支持资源运营和接入，但当前公开 SKU 均为 NVIDIA；报告未发现 AMD 或国产 GPU/NPU 的独立 SKU、同一任务的跨 XPU 迁移、统一账单、统一 SLA 或生产基准。因此，不能将多地域、多资源方或多模型目录等同于多厂商 XPU 能力。
- 中国铁塔案例可作为具名的官网案例线索；报告未取得双方合同、金额、验收、续期或其对 PPIO AI 云容量的证明，不把它写成订单或自有节点资产。

## 产业链分类建议

**主分类建议：**[8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)。高置信。客户购买的是按量计费的边缘云、GPU 容器、Spot、Serverless、模型 API 和 Agent 服务；收入承载物是服务容量、调用和资源运营，而非芯片、独立调度软件许可证或完整数据中心集成项目。

**正式次分类：不设。**

- 不建议归入 `4.4 多来源算力资源池化与控制面`：尚无至少两家 AI 芯片厂商的可购买资源、同一工作负载跨 XPU 迁移、统一运行时/基准/计费/SLA 的证据。
- 不建议归入 `4.1 跨厂商训推算力调度平台`、`3.4 容器化软件`、`3.5 调度与编排软件`或 `5.2 推理框架`：报告未证明独立软件授权、软硬件分离的控制面、可验证的客户生产实测，或 PPIO 拥有并交付独立推理框架。
- 若取得 AMD 或国产 XPU 的真实 SKU、跨芯片迁移、统一账单/SLA、生产基准与客户案例，才重新评估 `4.4`；若调度控制面以独立软件销售，再审查 `4.1` 或 `3.5`。

## 投资、并购与采购判断

- **投资：**列入可采购、可观察的基础设施服务商；在取得最新招股书、审计报表、资源合同、实际容量/利用率和客户/供应商重叠资料前，不基于公开资料作直接股权判断。
- **并购：**不建议。报告尚未证明可转移的多芯片调度 IP、独占 GPU 供给或机器人客户；控制权交易会带入节点运营、资源合同、云合规、模型 API 与客户集中风险。
- **采购：**先在非机密、可中断且可恢复的云端训练、仿真、数据处理、渲染或批推理中进行可退出 PoC；再以非安全关键的多模态助手、标注质检或研发 Agent 测试 Serverless/API。不得把云端模型 API 或 GPU 容器放入人形机器人的安全关键闭环控制。
- **自研：**优先自研工作负载容器化、数据脱敏、检查点、模型版本、跨云基准、成本归因和故障降级；除非外部云无法满足数据、成本或供应安全，不复制资源聚合和边缘节点运营网络。

## 风险、反证与触发条件

报告中支持 PPIO 作为可购买服务商的证据是公开的 GPU 容器、Serverless、模型 API 与在线购买入口；反证和缺口包括 AI 云仍为负毛利的媒体转述、客户集中度、第三方资源整合模式、资源资产/租赁比例未披露，以及跨 XPU 控制面缺少生产级实证。若 AI 云毛利未转正、前五客户集中度无法下降、Spot 中断或 SLA 争议增加，或客户/供应商重叠引发条款风险，应停止扩大采购或投资判断。相反，只有在资源权属、单位经济、服务 SLA 和跨 XPU 可复现实测均完成验证后，才提高合作深度。
