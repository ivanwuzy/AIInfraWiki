## Overview

蓝芯算力（深圳）科技有限公司是一个公开资料稀疏的早期 RISC-V＋AI 智算 CPU/服务器芯片项目。报告可追溯地记录其于 **2023-05-23** 成立、法定代表人为卢山；其“RISC-V＋AI 服务器 CPU”定位及与联想成立/拟设“RISC-V+AI 智通融合 CPU 联合创新实验室”的信息，均只能支持研发方向和产业合作线索，不能证明已发布产品、客户订单或商业化收入。截至研究截止日 **2026-08-06**，尚无可核验的芯片型号、流片/量产状态、公开 SDK、性能数据、客户订单或融资条款。因此它应作为需完成 P0 尽调的架构观察标的，而非成熟 AI 加速器供应商。

## 分类与业务边界

- **唯一主二级分类：`1.14 其他AI芯片架构（RISC-V/AI 服务器 CPU）`。** 公开定位是把 RISC-V 通用服务器 CPU 与 AI 加速融合的方向；现有分类中没有稳定的“AI 服务器 CPU/RISC-V CPU”子类。该归类描述的是其拟议价值创造位置，不表示其已有可验证的训练或推理产品。
- **次分类：无。** 截至截止日未找到可验证的 SDK、编译器、runtime、模型迁移/算子工具或跨节点软件栈，不满足 `2.1 加速计算平台（CUDA-like）` 的准入条件。若未来披露可审查的软件平台与真实部署，再重新评估。
- **不应提前归入 1.1、1.2、1.3 或 1.4。** 报告未提供可验证的 GPGPU 集群、TPU/NPU 成熟产品或图形渲染产品证据；不能用路线图替代已商业化能力。

## 技术与产品判断

其差异化命题是把通用服务器 CPU、AI 加速、内存/I/O 与可能的互联需求置于同一 RISC-V 平台。若 CPU 与加速单元可在统一地址、一致性及软件域内协作，理论上可能降低异构节点 BOM、数据搬运与部署复杂度；同时也必须同时解决 CPU 生态、操作系统、编译器、AI runtime、集群通信、板级可靠性和供应链等更宽的工程边界。

目前不能建立参数表或进行产品选型。需要在 NDA 下取得并独立复核：芯片型号及 RTL/FPGA/首硅/量产阶段，CPU 与 AI 单元的架构边界，PPA 与测试条件，内存/I/O/互联，虚拟化与隔离，Linux/编译器/框架支持，SDK release notes 与模型兼容矩阵，及板卡、服务器和供货可靠性数据。

## 对机器人战略的含义

### 采购、训练与数据闭环

- **训练：不进入核心训练路径。** 在缺少内存、互联、集合通信、框架、收敛与容错证据时，不能用其路线图替代 GPU/NPU 集群能力。
- **推理：仅在获得样品后验证固定工作负载。** 可从数据清洗、视觉回放、日志理解或私有 agent 推理等模型冻结、批量可控场景开始；以精度、P50/P95、并发、功耗、重启、内存占用和单位任务成本与基线对比，未通过前不签长期采购。
- **数据闭环：是最合理的潜在切入点。** 机器人多模态数据的筛帧、压缩、质检、脱敏、索引与回传可能受益于减少数据搬运；需验证端到端管线、时间同步、断网恢复、隐私、存储吞吐和人工复核召回率，而非只测模型吞吐。
- **自研芯片：作为问题定义参照而非替代方案。** 应从机器人端侧低功耗 NPU、视觉 SoC、控制 CPU 与数据中心训练/推理加速等具体工作负载倒推边界；在其产品验证前，不应把投资早期服务器 CPU 项目当作自研路线的替代。

### 投资与并购

**投资判断：观察级，适合带工程里程碑的小额技术期权，不宜在公开证据不足时进行高估值战略下注。** 若启动流程，建议将每阶段资金分别绑定于 RTL/仿真与关键团队/IP 核验、首版 silicon bring-up 与目标 PPA/Linux/编译器、客户板卡与量产良率/供货/回款。核心架构或软件负责人流失、目标性能未达标、供应许可不可获得或路线转为无边界定制，应构成停止加码的触发条件。

**并购判断：当前不启动整公司并购。** 在产品、资产与权属不透明时，整体收购可能接入未来研发开支、关联义务与未验证路线。较合适的前置动作是可退出的联合研发或 NRE 项目，例如多摄像头数据预处理服务器、低比特推理 runtime 或 RISC-V 控制平面，并通过源码 escrow、IP/软件权属和里程碑验收锁定价值。只有在取得完整 cap table、核心员工及 IP 清单，确认 RTL/验证环境/固件/编译器/SDK 权属，验证替代代工封测与板卡供应，且目标负载可复现通过后，才评估资产或团队并购。

## 下一步验证

1. **P0 产品与软件：** 获取型号、阶段、bring-up、PPA 与测试报告；在我方负载上以 SDK、容器、模型转换和 **30天** 稳定运行进行独立复跑。
2. **P0 供应与权属：** 审阅代工/封测/内存/板卡路径、交期、许可和替代方案；核对 cap table、增资协议、专利/代码权属、关联交易和质押。
3. **P1 合作与经济性：** 查验联想合作协议、样机、联合验收、SKU 与客户责任；以端到端吞吐、误筛率、功耗与存储/网络成本检验是否降低机器人数据闭环 TCO。
4. **P2 团队：** 核验核心负责人履历、留任、招聘与激励，以及覆盖架构、后端/DFT、验证、编译器/OS 与系统交付的组织完整性。
