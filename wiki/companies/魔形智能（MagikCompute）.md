## Overview

魔形智能（Magik Compute）是魔形智能科技（上海）有限公司的对外品牌；其公开可核验商品是 MagikCloud 上按量、预付费的模型 API／Token 服务。应将其归为[8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)中的“大模型 Token 推理服务／运营”，而非推理调度平台。官网对“自研高性能推理引擎”和“创新超节点算力集群”的表述，是服务商自述，尚不足以确认独立可交付的推理框架、跨厂商资源池或 Prefill/Decode（P/D）分离能力。[来源：本页 Raw]

## 主体、品牌与资产边界

服务条款、隐私政策与充值协议将 MagikCloud 的网站、客户端、应用及平台经营者指向魔形智能科技（上海）有限公司；官网招聘入口也跳转至以该全称登记的飞书招聘租户。因此，“Token超级工厂”“Magik Compute”与“MagikCloud”可被记录为该法人的品牌或产品体系，不能写成独立融资主体或当然可剥离、可收购的资产。[来源：本页 Raw]

这一主体闭环只覆盖服务运营。条款同时允许未列名关联公司提供部分服务，并将内容和知识产权归于公司、关联公司或相关权利人；GPU／机房、超节点、软件著作权、商标、模型许可、客户合同及收入确认主体均未穿透。公开搜索卡片所列 2024-06-03 成立、徐凌杰法定代表人、1,000 万美元注册资本及融资线索，均为第三方摘要，不能替代工商原件、股东名册或交割文件。[来源：本页 Raw]

## 产品与分类判断

- **主类型：**[8.1 云与 AI 算力服务](../segments/8.1-云与AI算力服务.md)（中高置信）。可验证的交付是带 Endpoint、RPM/TPM、提示词缓存、用量统计、工具调用与结构化输出的模型 API／Token 服务；其计费为按 Token、预付费，而非可审计的底层算力控制面。[来源：本页 Raw]
- **5.2 推理框架：仅条件性观察，不列入正式次类型。** “自研高性能推理引擎”及 API 功能不等同于有名称、版本、独立部署／授权方式、硬件与模型兼容矩阵、第三方基准及明确 IP 归属的推理框架。[来源：本页 Raw]
- **4.4 多来源算力资源池化与控制面：不成立。** 没有至少两家 XPU 厂商的接入清单、统一池化／计量／结算、供应商选择或故障切换证据。[来源：本页 Raw]
- **4.2 推理 PD 分离：不成立。** Endpoint、前缀哈希路由与 prompt cache 不能证明 Prefill/Decode 拆分、独立扩缩、KV cache 跨节点传输、配比策略或生产 SLO。[来源：本页 Raw]

## 商业与技术成熟度

公开产品面支持将其作为云端模型调用候选：账号、API Key、模型目录、模型参数、缓存与错误计费规则表明其已进入产品化服务阶段。但“承载千亿级 Token 并发”“历经严苛生产环境验证”等为公司主张，缺少模型、输入输出长度、TTFT、TPOT、错误率、缓存命中、卡型、集群规模、能耗、客户验收或独立压测，不能用于采购 SLA、收入、容量或估值判断。[来源：本页 Raw]

媒体索引在 2026-05-06 一致报道“数亿元 Pre-A”，并列出达泰资本领投、上海半导体产投跟投。这可作为融资报道及团队招募能力线索，却没有签约法人、到账、估值、持股、优先权或工商变更，不能建立 cap table 或把投资方记为已证实股东。[来源：本页 Raw]

## 对机器人公司的处置

采购可限于 6–8 周、双供应商、可迁移的云端 VLA／Agent 受控 PoC；固定模型版本、上下文、工具调用与并发条件，比较 TTFT、TPOT、p95/p99、成功率、缓存命中、有效任务成本、故障回退及数据删除。它不应承接端侧实时控制或唯一云端通路。[来源：本页 Raw]

投资应暂缓，直至获得逐轮交易文件、最新 cap table、资金到账、客户 cohort、单位经济及关键 GPU／IP 承接证据；整体并购不建议启动。若未来技术与权属可验证，只评估可分拆的工程团队或软件资产，并审阅 SBOM、发明转让、模型／云／机房合同与数据责任。详见[魔形智能主体、资产与服务能力尽调](../questions/魔形智能主体、资产与服务能力尽调.md)。[来源：本页 Raw]

## 冲突与不确定性

公开法律与产品页面支持“该上海法人运营服务”的结论；同一条款却保留关联公司提供服务和权属分散的可能。媒体融资报道与可交易资产、可审计收入或实际控制权之间亦没有同等证据闭环。上述冲突不能平均为“公司已拥有完整自研基础设施”，应在采购、投资或并购前完成穿透验证。[来源：本页 Raw]
