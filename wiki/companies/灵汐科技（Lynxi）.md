## Overview

灵汐科技（研究对象：北京灵汐科技有限公司，Lynxi Technologies）是类脑／神经形态 AI 芯片与计算系统公司。公开材料显示其以 DNN/SNN 混合计算为路线，已发布领启 KA200(-S) 及配套模组、PCIe 卡、边缘设备、服务器和 LynOS 软件栈。现有资料支持将其作为面向稀疏、事件驱动、低功耗或强时序子负载的技术观察及受控 PoC 候选；不支持将其描述为通用 GPU 替代者、人形机器人规模化主控供应商，或已有经独立核验的订单、收入和大批量出货。[灵汐科技Lynxi横纵分析报告](../../raw/sources/2026-08-12-灵汐科技Lynxi横纵分析报告.md)

## 主体、名称与路线边界

- **研究对象：** 北京灵汐科技有限公司（Lynxi Technologies）。本页 H1 采用对外常用简称“灵汐科技（Lynxi）”，不据此推定股权、控制权或 IP 权属。
- **技术脉络不等于资产承继：** 2019 年的 Tianjic（天机）混合类脑研究、论文作者单位中的 Lynxi Technologies, Beijing，以及清华大学类脑计算研究脉络，支持研究与人才关联；均不证明 Tianjic 与 KA200 是同一芯片，也不证明 Tianjic 的全部 IP 已注入北京灵汐科技有限公司。
- **同类技术不构成实体关系：** SynSense、BrainChip 和 Intel Loihi 是报告中的横向神经形态路线参照，不记录为灵汐科技的关联主体、产品或客户。
- **感知线路边界：** Lyncam 的公开状态为工程样片点亮；2024 年类脑互补视觉感知成果为研究合作与公司转述的技术结果。二者均不等同于已量产、可供货的机器视觉产品。

## 客户购买物、产品与商业证据

- **已公开交付物：** KA200(-S) 芯片及围绕其的模组、加速卡、边缘产品、服务器和 LynOS 软件栈；这说明公司公开呈现芯片到系统的软件／硬件产品族，而不是仅有论文或单板展示。
- **公司自述与独立验证的边界：** 公司新闻在 2024 年称 KA200(-S) 已“发布并量产”，产品页面列出 DNN/SNN 混合、众核并行和事件／控制流调度等能力。应记录为公司自述的产品状态和规格，不能外推为规模出货、第三方性能胜率、客户复购或收入确认。
- **客户／订单：** 当前报告未发现 KA200、HM100 或 HP100 的具名客户合同金额、采购数量、验收、持续复购或收入确认。HM100 页面列出机器人、无人机和智能摄像机等目标场景，不构成机器人客户证据。
- **合作／资本：** 2021 年媒体报道一轮融资有海康威视、卓源资本、新鼎资本、无锡武吉士和宁波灵知参与，但金额未披露；这既不是现行股东名册，也不能证明海康威视采购、渠道绑定或技术授权。公司作为核心单位参与电力行业类脑平台及智能体项目，属于应用示范合作，未披露灵汐的供货范围、合同额或验收，不能列为芯片销售收入。

## 分类建议（供协调器同步）

- **正式主分类：** `1.12 类脑芯片`。客户若购买其交付物，核心购买理由应是混合类脑计算及其系统实现，而非传统 GPGPU、常规 NPU 或独立集群软件。
- **正式次分类：** 不设。LynOS 是 KA 系列的配套软件栈，但公开资料不足以满足 `2.1 加速计算平台（CUDA-like）` 的完整度、可扩展性、工作负载广度和开发者产品化准入；Kubernetes／Slurm 插件也不能证明独立的 `3.5` 或 `3.6` 业务。
- **不归 `1.6` 或 `1.3`：** “存算一体”术语未证明阵列内计算介质、计算位置和对应商业交付，故不升级为 CIM/PIM；KA200 的 INT8／FP16 能力也不足以抹去其以 DNN/SNN 融合与类脑映射为核心差异的主路线。
- **不归模型类别：** 未见已公开的 VLA/WAM 产品、模型交付或机器人订单，不归 `6.5` 或 `6.6`。

## 机器人战略动作

| 动作 | 当前结论 | 进入条件／限制 |
|---|---|---|
| 采购／联合 PoC | 建议受限开展 | 先取得 KA200/HM100/HP100、可离线安装的 LynOS、支持矩阵、BOM、供货／保修和版本锁定策略；仅测试事件视觉、语音唤醒、局部异常检测、固定感知网络或小型混合 SNN/DNN 负载。 |
| 系统部署 | 暂不建议扩大 | 保留成熟 GPU/NPU 主控基线；不得承载频繁迭代的 VLA／大语言模型、训练任务或全身控制安全关键闭环。 |
| 战略投资 | 技术观察，可选小额合作 | 需先核验最近两代芯片状态、晶圆／封装／可靠性与供货计划；取得至少两家可访谈的付费客户或可核验验收材料，并披露股权、IP 和重大限制。 |
| 控制权并购 | 当前不建议 | 先完成核心 IP／许可范围、可持续客户收入、芯片与软件可转移性、供应保障及关键工程师留任的尽调；优先联合 PoC、参考设计和里程碑式合作。 |
| 自研 | 不从零自研通用类脑芯片 | 自研重心保留在事件／高动态感知的数据表示、任务网络、端侧运行时／调度、安全监测、模型压缩及异构系统集成；只有 PoC 证明不可替代优势后再讨论定向 IP／芯片共研。 |

## 风险、反证与关键未知

- **路线反证：** DNN/SNN 混合的价值需在我方实际模型上证明；若 Transformer/VLA 的算子、量化、内存与调试支持不足，成熟 GPU/NPU／事件相机组合可能在开发速度、工具链和供应链上占优。
- **产品化风险：** 感知端目前仅见工程样片与研究成果，缺少公开量产 SKU、模组、SDK、封装／良率、供货与客户证据；KA200(-S) 的“量产”也只有公司自述，缺少累计出货和第三方核验。
- **尽调与触发条件：** 需按同一相机、输入、温度和功耗仪器，对比吞吐、P50/P99、整板能耗、DDR、热稳定性和连续 7×24 小时；关键模型无法转换、端到端收益不成立、供货／可靠性／支持不达标时退出。详见[灵汐科技关键尽调问题](../questions/灵汐科技关键尽调问题.md)。
