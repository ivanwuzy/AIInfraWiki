# 8.2 量子计算

量子计算研究簇，归属于 `8 其他`。本分类用于承载技术路线相对清晰、但尚未适合归入 AI 芯片或算力服务分类的量子计算候选；分类本身不代表产品化、设备交付或商业收入已经成立。

## 共同边界

- 当前纳入的图灵量子、矩量光启、两仪万象、奇算光启，均未形成足以支持采购的完整闭环：产品化和设备交付、客户／任务、云 API 或商业定价仍待核验。
- 量子比特、论文、融资、工程化计划或“量子 + AI”叙事，不等同于可交付 QPU、整机、软件、云服务或客户收入。
- 相对 GPU/HPC 的机器人工作负载优势尚未证明。任何 PoC 都应对照经典基线，覆盖问题规模、解质量、端到端延迟、稳定性、异常恢复和总成本；不得进入训练、VLA 推理、关节控制或其他关键生产路径。
- 超导、中性原子、光量子等路线属于不同技术实现，暂因研究与采购边界相近而归入同一索引簇，不据此推断产品或商业模式相同。

## 升级与迁移条件

只有在同一法定主体下同时取得可复现产品／服务边界、设备或 API 交付、客户合同／任务与验收／回款，以及核心 IP 和售后责任材料后，才评估是否形成更具体的技术或服务分类。若客户实际购买的是通用 GPU 云、经典光电加速卡或数据服务，应按客户购买物和收入承载物迁移，不因“量子”名称保留在本类。
