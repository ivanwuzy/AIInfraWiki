# 3.4 容器化软件

集群容器化软件环节，含 5 家正式主类型公司、3 家正式次类型公司及 2 家条件性观察候选。

## 主类型

| 公司 | 说明 |
|------|------|
| [道客（DaoCloud）](../companies/道客（DaoCloud）.md) | DCE 5.0 是其公开产品层级最明确的 Kubernetes/容器平台交付；客户、收入、SLA 与部署规模仍需核验。 |
| [博云（BoCloud）](../companies/博云（BoCloud）.md) | BOC 是官网展示的企业级算力容器平台，故为主类型；其自研比例、开源许可证、性能、客户生产规模与 SLA 均待核验。 |
| [易捷行云（EasyStack）](../companies/易捷行云（EasyStack）.md) | EKS 是公开的企业 Kubernetes 容器平台与私有化部署/服务交付；产品、支持、客户、控制权和可交易资产仍须核验。 |
| [时速云（TenxCloud）](../companies/时速云（TenxCloud）.md) | TCAP 是企业容器 PaaS、应用生命周期与运维交付的公开产品面；以北京云思畅想为唯一责任主体，代码、合同、服务与控制权均待 P0 核验。 |
| [谐云科技](../companies/谐云科技.md) | HC-PaaS 的 Docker/Kubernetes 企业 PaaS 产品面是当前最贴近客户购买与可能交付/收费承载物的证据；主体、IP、版本、SLA、生产验收和独立收入仍待核验。 |

## 次类型

| 公司 | 次类型标签 | 说明 |
|------|-----------|------|
| [Spectro Cloud](../companies/SpectroCloud.md) | 次类型、中等置信 | Palette Profile 管理 Kubernetes 全栈部署与容器应用所依赖的网络、存储和附加服务；不是独立容器运行时或 Kubernetes 发行版的主要价值承载。 |
| [云轴科技（ZStack）](../companies/云轴科技（ZStack）.md) | 次类型、中等置信 | Zaku 以 Kubernetes、IaaS 扩展和独立容器云为公开产品形态；GPU 隔离、支持矩阵、生产规模与 SLA 仍待核验。 |
| [青云科技（QingCloud）](../companies/青云科技（QingCloud）.md) | 次类型、中等置信 | Kubernetes 容器平台、应用生命周期、容器云交付与应用分发是已发布能力；公开资料未按其拆分收入，GPU资产/租赁、容量与生产 SLA 待核验。 |

## 条件性观察候选

| 公司 | 当前主分类 | 升级条件 |
|------|------------|----------|
| [灵雀云（Alauda）](../companies/灵雀云（Alauda）.md) | `8 其他` | 证明北京凌云雀科技有限公司拥有或获许可销售 ACP／企业容器平台，且承担版本支持、合同、交付、开票、SLA 和数据责任；品牌展示本身不成立。 |
| [飞致云（FIT2CLOUD）](../companies/飞致云（FIT2CLOUD）.md) | `3.6 集群管理软件` | KubeOperator 历史自研叙事及 1Panel 的 Docker 容器管理不证明当前 Kubernetes 控制面、版本维护、SKU、收入或生产交付；须取得相应证据后再升级。 |
