# 3.5 调度与编排软件

集群调度与编排软件环节，含 2 家高置信主类型公司、7 家正式次类型公司及 4 家条件性观察候选。

## 主类型

| 公司 | 说明 |
|------|------|
| [CAST AI](../companies/CASTAI.md) | Kubernetes 资源画像、rightsizing、节点选择、扩缩、bin-packing 与重平衡的自动化执行层；不作为 GPU 供应或完整训推平台。 |
| [趋动科技（VirtAI Tech）](../companies/趋动科技（VirtAITech）.md) | OrionX 公开承担资源发现、vGPU 调度、申请／释放、队列、优先级、抢占及 Kubernetes 调度扩展；其可审计核心仍是 NVIDIA CUDA GPU 池化，而非已验证的跨 XPU 调度。 |

## 次类型

| 公司 | 次类型标签 | 说明 |
|------|-----------|------|
| [Anyscale](../companies/Anyscale.md) | 次类型、较高置信 | Platform 公开交付跨云/区域、K8s/VM、优先级调度、队列、GPU 资源池与自动扩缩；不将其列为跨厂商训推算力调度平台。 |
| [道客（DaoCloud）](../companies/道客（DaoCloud）.md) | 次类型、中等置信 | DCE 的应用编排与 d.run 的资源池、异构纳管、队列/抢占等公开能力支持次类；无跨厂商兼容矩阵、生产验收或独立性能证据。 |
| [Spectro Cloud](../companies/SpectroCloud.md) | 次类型、中等—较高置信 | Palette 的声明式 Profile、跨环境集群编排、配额、升级和恢复属于基础设施生命周期编排；不视为训练作业调度或跨 XPU 推理路由。 |
| [北电数智（BeDiCloud）](../companies/北电数智（BeDiCloud）.md) | 次类型、低—中等置信 | 前进的异构计算定位及算力中心纳管调度线索支持保留次标签；缺独立软件版本、架构、接口、客户、收费、SLO 与故障恢复证据。 |
| [博云（BoCloud）](../companies/博云（BoCloud）.md) | 次类型、中等置信 | ACE 的异构资源池化、虚拟化、切分与调度策略构成产品级依据；缺目标卡/驱动矩阵、独立性能、生产验收、SLA 与收入闭环。 |
| [青云科技（QingCloud）](../companies/青云科技（QingCloud）.md) | 次类型、中等置信 | GPU 资源调度与多集群部署是已发布能力；公开资料未按其拆分收入，且不证明大规模低成本跨厂商训练平台或多来源算力资源池化与控制面。 |
| [时速云（TenxCloud）](../companies/时速云（TenxCloud）.md) | 次类型、中等置信 | TCAP/AIStack 的集群联邦、混合编排、资源管理和弹性伸缩构成产品主张；缺版本矩阵、规模测试、客户验收与独立服务责任。 |
