# 1.4 图形GPU（桌面／工作站／专业可视化）

图形渲染、显示输出、视频编解码与专业可视化的 GPU 环节。

有关 1.1 与 1.4 的边界判定，见 `产业链分类规则.md`。

## 主类型

| 公司 | 说明 |
|------|------|
| [格兰菲（Gelanfei）](../companies/格兰菲（Gelanfei）.md) | 图形独显与显示芯片并行布局；主分类仅计图形 GPU。 |
| [砺算科技（Lisuan）](../companies/砺算科技（Lisuan）.md) | 消费与专业图形 GPU；LSRT/TVM 后端尚未形成符合 2.1 的平台。 |
| [芯瞳半导体（XintongSemiconductor）](../companies/芯瞳半导体（XintongSemiconductor）.md) | 信创图形显示与专业渲染 GPU；未见达到 2.1 门槛的软件平台证据。 |
| [象帝先（Xiangdixian）](../companies/象帝先（Xiangdixian）.md) | 图形渲染、视频编解码与边缘/工作站并行计算 GPU，主分类 1.4。 |
| [景嘉微（JingjiaMicro）](../companies/景嘉微（JingjiaMicro）.md) | 高可靠图形显控与专业图形 GPU；JM11 的云桌面、工作站和虚拟化推广不外推为已验证的通用 AI 训练／推理平台。 |
