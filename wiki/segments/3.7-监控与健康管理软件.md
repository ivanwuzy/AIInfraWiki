# 3.7 监控与健康管理软件

集群监控与健康管理软件环节；含 3 家主类型公司、4 家正式次类型公司和 5 家条件性观察候选。

## 主类型

| 公司 | 说明 |
|------|------|
| [Chronosphere](../companies/Chronosphere.md) | 云原生 metrics、logs、traces、SLO 与 Telemetry Pipeline；已被 Palo Alto Networks 收购，适合作为可替换的训练／推理集群可观测性采购候选，不是独立股权交易标的。 |
| [Datadog](../companies/Datadog.md) | 统一 metrics、traces、logs 与安全信号的按用量 SaaS 可观测性平台；适合云端训练/服务和车队后端 PoC，不等于 Kubernetes 集群控制、作业调度或机器人端功能安全。 |
| [博思芯宇（Bosi Xinyu）](../companies/博思芯宇（BosiXinyu）.md) | 芯片/节点状态采集、健康建模、故障与能耗管理候选；公司材料与公开项目线索支持产品方向，性能、软件收入、客户验收和 IP 权属待核验。 |

## 次类型

| 公司 | 次类型标签 | 说明 |
|------|-----------|------|
| [道客（DaoCloud）](../companies/道客（DaoCloud）.md) | 次类型、中等置信 | DCE 的 monitoring/observability 与 d.run 的可观测、实时监控和审计为产品层证据；告警质量、MTTR、留存、SLA、独立性能和收入边界待核验。 |
| [时速云（TenxCloud）](../companies/时速云（TenxCloud）.md) | 次类型、中等置信 | TCAP/AIStack 的日志、告警与可观测性是产品主张；告警质量、指标留存、MTTR、SLA、独立收费和生产验收均待核验。 |
| [飞致云（FIT2CLOUD）](../companies/飞致云（FIT2CLOUD）.md) | 次类型、待核验 | CloudExplorer 的 Prometheus 统一监控告警及官网销售的 Zabbix 信创一体机和管理/数据可视化软件构成监控方案证据；Zabbix IP、原厂订阅和第三方组件不当然归属飞致云。 |
| [谐云科技](../companies/谐云科技.md) | 次类型、待核验 | Cloud Nevro、Nevro Alert 与 Metrics/Tracing/Logging 的产品方向支持次类；版本、SLA、生产验收、独立收入与主体/IP 承接仍待核验。 |
