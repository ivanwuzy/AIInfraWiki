# 3.6 集群管理软件

集群管理软件环节，含 5 家较高置信主类型公司、7 家正式次类型公司及 4 家条件性观察候选。

## 主类型

| 公司 | 说明 |
|------|------|
| [Cloudera](../companies/Cloudera.md) | 收购 Taikun 后以 Cloud Factory 提供多云／私有云 Kubernetes 与云基础设施的创建、导入、升级、审计、配额和 IaC 控制面；独立 SKU、收入、客户、SLO 与 CDP 整合仍待核验，不列为跨 XPU 调度或资源池化平台。 |
| [Spectro Cloud](../companies/SpectroCloud.md) | Palette／PaletteAI 以 Profile 管理跨云、数据中心、bare metal 与边缘 Kubernetes 集群的部署、升级、恢复、治理和断网场景；不将其写为推理运行时或跨 XPU 调度。 |
| [云轴科技（ZStack）](../companies/云轴科技（ZStack）.md) | 私有云、虚拟化、容器、存储、多云与 AIOS 组合的企业基础设施控制面；对大规模 GPU 训练的调度、升级与生产交付仍须以可回滚 PoC 验证。 |
| [飞致云（FIT2CLOUD）](../companies/飞致云（FIT2CLOUD）.md) | CloudExplorer 面向公有云、私有云、超融合与容器云的统一入口、自助交付和企业控制面；多 Kubernetes 集群统一门户、租户、权限、配额、运营分析与计量为产品证据，资产、融资和 AI 集群交付待核验。 |
| [青云科技（QingCloud）](../companies/青云科技（QingCloud）.md) | KubeSphere 企业版/QKE 的 Kubernetes 多集群、租户、应用生命周期、混合环境治理与控制面为独立产品化交付物；版本、许可证、权属、GPU资产/租赁、容量与生产 SLA 待核验。 |
