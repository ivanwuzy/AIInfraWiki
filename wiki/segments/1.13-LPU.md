# 1.13 LPU

以数据流执行、确定性调度、片上存储和专用编译器为核心的语言或实时推理处理器及系统。LPU 仍需按已交付芯片、软件、客户和收入证据判断，不因融资材料或路线图中的“LPU”命名自动视为量产产品。

## 主类型

| 公司 | 说明 |
|------|------|
| [Groq](../companies/Groq.md) | LPU 专用推理硬件、系统与 GroqCloud；主要面向云端语言推理，不是通用训练平台。 |
| [元川微（ArcheFlowX）](../companies/元川微（ArcheFlowX）.md) | LPU+ 硬数据流推理芯片项目；目前处于原型、首硅和客户验证阶段。 |
| [迈特芯（Maitex）](../companies/迈特芯（Maitex）.md) | 端侧 LPU/CPU+FPGA 异构路线早期标的；产品、IP 和商业化待核验。 |

## 分类边界

- 不因使用编译器、数据流或片上 SRAM 就自动归入 `2.1 加速计算平台` 或 `1.6 存算一体/近存计算芯片`。
- 若主要交付物变为固定功能端侧 NPU、GPGPU 或 FPGA-DPU，应按实际产品和收入承载物迁移。
