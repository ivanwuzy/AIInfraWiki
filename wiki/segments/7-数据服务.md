# 7 数据服务
#mainsegment

一级分类，暂无二级分类。

尚未定义二级分类。当前将以客户自有机器人数据的接入、可视化、检索、协作、回放和训练/评估筛选为收入承载的软件平台归入本类；相关合成数据、数据闭环或数据处理线索仍保留在各公司页中，待形成稳定的收入承载物差异后再建立二级分类。

## 主类型

| 公司 | 说明 |
|------|------|
| [Foxglove](../companies/Foxglove.md) | 机器人多模态数据的接入、可视化、索引、搜索、协作、回放与训练/评估筛选工作流；销售客户自有数据的软件平台，不是训练数据集或标注服务。 |
| [Parallel Domain](../companies/ParallelDomain.md) | 将客户真实 capture logs 重建为数字 Replica，并交付多传感器仿真、标签、场景变化和质量报告；收入承载是机器感知训练、验证与评测的数据/测试资产，不是通用模型框架。 |
| [Rerun](../companies/Rerun.md) | 面向 Physical AI 的多模态记录、可视化、编目、查询、变换与训练读取工具；客户处理自有数据，Hub 仍为 private preview，不视为已验证的托管数据湖、训练数据或标注服务。 |
| [Surge AI](../companies/SurgeAI.md) | 高质量标注、偏好比较、模型评测与 RLHF 人类反馈服务的候选；公开产品、客户、数据权属、人员治理与具身多模态能力尚待合同和 PoC 核验。 |
| [数据堂（Datatang）](../companies/数据堂（Datatang）.md) | 基础数据资源授权、定制采集／标注及数据处理方案供应商；具身数据是明确扩展方向，但数据集级权属、本体适配和具身商业化须独立核验。 |
| [曼孚科技（MindFlow）](../companies/曼孚科技（MindFlow）.md) | DaaS 数据标注、数据处理、自动标注、数据管理和项目化质量运营服务商；不将场景展示外推为客户、订单、数据所有权或模型训练权。 |
| [海天瑞声（Speechocean）](../companies/海天瑞声（Speechocean）.md) | 定制训练数据、标准化可许可数据产品及数据相关应用服务商；具身智能覆盖不外推为机器人订单、可转让数据资产或真机效果。 |
| [奇点云（StartDT）](../companies/奇点云（StartDT）.md) | 杭州比智科技有限公司的企业数据基础设施、治理与数据智能应用品牌；数据目录、质量、血缘、权限及数据服务接口可作机器人非核心数据治理 PoC，不能外推为训练／推理或集群基础设施。 |
| [数澜科技（DTWave）](../companies/数澜科技（DTWave）.md) | 数栖数据平台与行业实施的数据工程、治理、资产化和数据服务候选；企业大模型、智能体、容器云、模型训推及 GPU 调度尚无独立计费或外部验收证据。 |
