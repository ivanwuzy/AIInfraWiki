# 5.1 训练框架/运行时

对标 PyTorch、TensorFlow、JAX、OneFlow 的模型训练编程与执行平台。必须提供面向开发者的训练 API 与独立运行时，能够承载多个模型和训练任务；训练加速项目、算子适配和 MLOps 不纳入。

## 主类型

| 公司 | 说明 |
|------|------|
| [一流科技（OneFlow）](../companies/一流科技（OneFlow）.md) | PyTorch-like API、Global Tensor、Graph Compiler 与公开运行时对标训练框架；商业化、目标芯片覆盖和机器人工作负载效果仍须验证。 |
