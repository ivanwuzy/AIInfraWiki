# 5.4 推理应用编排与知识库框架（企业 Agent 与知识系统）

推理应用编排与知识库框架环节，别名为“企业 Agent 与知识系统”。面向 RAG、知识库、工具调用、Agent、企业数据和业务流程，不等同于 `5.2` 推理执行引擎。

## 主类型

| 公司 | 说明 |
|------|------|
| [数巅科技（Dipeak）](../companies/数巅科技（Dipeak）.md) | AskBot、AskDoc 与 AskBI 面向企业知识库、任务拆解、工具调用、数据问答和应用编排；主体、IP、客户合同、商业质量与生产安全仍待核验。 |
| [第四范式（4Paradigm）](../companies/第四范式（4Paradigm）.md) | AI Platform、API 与 Agentic AI 组合面向企业数据、模型、资源和业务流程的部署治理、知识/流程连接与 Agent 编排；AI Platform 收入为平台/交付组合，不能等同纯 SaaS ARR，机器人收入未披露。 |

## 次类型

| 公司 | 次类型标签 | 说明 |
|------|-----------|------|
| [Baseten](../companies/Baseten.md) | 中置信；限推理应用编排 | Chains、异步推理、结构化输出与 function calling 支持推理工作流/服务编排；未见 RAG 数据治理或企业知识库能力的充分证据。 |
