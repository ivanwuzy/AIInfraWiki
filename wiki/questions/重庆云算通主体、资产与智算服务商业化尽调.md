# 重庆云算通主体、资产与智算服务商业化尽调

> Sources: 横纵研究报告，研究截止日 2026-08-11
> Raw: [重庆云算通科技有限公司横纵分析报告](../../raw/sources/2026-08-12-重庆云算通_横纵分析报告.md)
> Updated: 2026-08-12

## Overview

本页核验重庆云算通科技有限公司是否实际拥有可交付的 GPU 云、区域项目／资源撮合服务或软件控制面，以及相应资产、客户合同和收入。在同一法人下的主体、资产与服务证据形成闭环前，[重庆云算通](../companies/重庆云算通.md)维持正式主分类[8 其他](../segments/8-其他.md)，无正式次分类；不把名称、候选剧本或“万卡”“智算中心”表述作为商业事实。[来源：本页 Raw]

## P0 尽调问题

1. **主体与品牌：**取得统一社会信用代码、设立及历史变更、法定代表人、股东与实控人材料，核验“重庆云算通”品牌、关联方、合同主体与法人是否一致。[研究建议；报告称法人与品牌未闭环]
2. **资产与许可：**取得机房、GPU、网络、存储、软件控制面及相关设备的所有权或可使用权文件，并以增值电信许可、招投标、官网历史和运维资料核验实际经营范围；不得由“云算”名称推定资产或服务能力。[来源：本页 Raw]
3. **产品与服务交付：**取得 GPU 云 SKU、可用 GPU 小时、网络／存储配额、计费、SLA、故障责任、性能、可用性与多厂商兼容矩阵；目前缺少这些资料，不能与云厂商 GPU 实例、区域 IDC、服务器托管商或内部集群定量比较。[来源：本页 Raw]
4. **商业化：**取得客户购买物、客户合同、项目合同与验收、收入、发票／审计资料及非关联客户持续使用证据；在此之前，不认定形成 GPU 云、集成项目、调度软件或其他算力服务的订单、收入或商业化。[来源：本页 Raw]
5. **IP、团队与供应链：**穿透软件 IP、运维团队、关键设备与供应链的归属、责任和可转让性，判断危险剧本“主体仅为管理壳”能否被证伪。[研究建议；报告将 IP、运维团队和供应链列为未确认事项]

## 决策闸门

- **采购：**当前不进入生产采购。只有同一法人下的 GPU 服务能力、网络／存储配额、SLA、故障责任、数据责任、项目验收与资产权属均可审计后，才考虑可逆的非生产验证。[研究建议；报告仅允许主体与资产隔离核验]
- **投资：**当前不投资。须先完成主体、资产、客户合同、收入、融资、IP、运维团队与供应链的交叉核验，不以资源撮合、万卡或智算中心叙事替代商业化事实。[来源：本页 Raw]
- **并购：**当前不并购。只有存在权属清晰、可转让且经合同、验收和资产材料验证的业务或资产，才评估交易边界与机器人协同。[研究建议；报告称当前不进入并购]

## 分类触发与证伪

若无法提供可审计 GPU 云交付，应继续保持主分类 8 其他、无正式次分类。只有取得可审计 GPU 云交付后，才重新评估 8.1 云与 AI 算力服务或 3.3 算力中心集成；若进一步主张 4.4 多来源算力资源池化与控制面，还须有多厂商兼容的可核验材料，不能由名称或单一资源撮合推断。[来源：本页 Raw]
