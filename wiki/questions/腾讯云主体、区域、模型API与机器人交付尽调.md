## Overview

这是影响[腾讯云（Tencent Cloud）](../companies/腾讯云（TencentCloud）.md)采购、合作和数据治理的 P0 开放问题。腾讯云是品牌与业务体系，而非单一可交易法人；腾讯云计算（北京）有限责任公司是年报可确认的中国境内法人锚点，但订单、区域、数据处理、支持及模型 API 责任不能由品牌或集团能力替代。[来源：本页 Raw]

## P0 核验事项

| 问题 | 当前支持证据 | 缺失或反对证据 | 下一步验证与决策影响 |
|---|---|---|---|
| 中国订单的实际卖方和责任主体是谁？ | 腾讯集团 2024 年报列示腾讯云计算（北京）有限责任公司为 `100%` 持股子公司、注册资本人民币 `10.425` 亿元，主营信息系统集成服务。 | 年报未证明该法人是全部中国腾讯云 SKU、项目或模型 API 的唯一卖方。 | 对每个 SKU 取得订单、发票、服务协议、DPA、支持单和事故通知，核对统一社会信用代码、处理方与违约责任。 |
| 海外区域能否由同一主体、同一 DPA 承接？ | 国际站、区域服务协议和订单可构成各区域合同依据。 | 公开入口不能替代客户签署版本，也不证明数据不出境或北京法人承担责任。 | 采购前取得区域实体、分处理者、数据流、存储/备份位置和跨境义务的书面披露；未完成前不上传生产机器人数据。 |
| 混元 API 的输入输出、留存和地域边界是什么？ | 官方发布确认混元通过腾讯云面向企业开放。 | 公开发布不等于特定企业条款；输入是否训练、保存多久、能否指定地域仍未确认。 | 审阅 API 补充协议与控制台配置，并以日志审计验证留存、使用、模型版本、限流、输出权利及删除机制。 |
| 是否已有可复用的人形机器人交付能力？ | 腾讯云可组合计算、存储、网络、容器、模型 API、音视频、IoT/边缘连接与安全等候选产品族。 | 未找到足以证明人形机器人订单、VLA/WAM 框架或机器人数据服务的公开一手证据。 | 要求同类匿名案例、架构、验收材料和 SLO；无证据时仅将相邻能力纳入小范围 POC，不作商业承诺。 |
| 算力供给与单独经济性是否可承诺？ | 腾讯年报披露集团 `2024` 年资本开支人民币 `767.60` 亿元，并确认云服务按订阅或资源消耗确认收入。 | 未单独披露腾讯云收入、毛利、GPU 规模、型号、区域配额、排队或价格。 | RFP 获取目标区域的芯片/驱动/框架、配额、排队、单位有效训练步成本、网络/存储和价格/SLO 承诺。 |

## 决策门槛

在合同相对方、数据处理地域、模型 API 输入输出使用、可用容量、SLO、退出迁移和事故责任书面闭环前，不将腾讯云作为唯一训练、生产推理、数据闭环或备份供应商。通过后，仍以供应商中立的容器、对象存储格式、数据集索引、checkpoint、权限和推理服务迁移演练约束锁定风险；该问题页不构成对腾讯集团其他资产、技术或投资组合的承接认定。[来源：本页 Raw]
