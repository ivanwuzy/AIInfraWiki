## 问题

北京趋境科技有限责任公司能否在明确主体、资产、数据和供应切换权的前提下，作为可持续交付的异构推理与 Token 生产服务供应商？本问题归属于[趋境科技（Approaching.AI）](../companies/趋境科技（Approaching.AI）.md)。

| 尽调问题 | 支持证据 | 反对证据或缺口 | 下一步验证 |
|---|---|---|---|
| 目标法人能否承接品牌、区域交付与客户合同 | 官网以北京趋境科技有限责任公司全称介绍三类 Token 产品，品牌材料亦将趋境科技／Approaching.AI 对外服务相连。 | 未见统一社会信用代码、工商沿革、关联方图、商标／软件著作权、区域总部、历史合同、收入或负债承接文件。 | 取得工商档案、章程、股权图、关联方清单、品牌／商标／软件权属和合同／收入按法人分拆表。 |
| ATaaS、Token System 与 Token Machine 的 IP 和开源边界是否可交割 | 公司材料描述产品能力与整机、授权、联合运营模式；KTransformers、Mooncake 和清华成果存在参与或作价增资线索。 | 未见源代码、许可证、贡献者协议、员工成果、技术资产清单、作价报告、排他范围、商业支持权或客户合同承接证明。 | 审阅代码仓、SBOM、开源许可证与贡献记录、雇佣／发明协议、技术作价文件、专利／商标／软件权属及第三方许可。 |
| Token 生产服务是否具备真实的客户、收入和单位经济 | 报道称 ATaaS 向智谱 GLM、月之暗面 Kimi 等客户提供服务，且公司公开 Token 服务和联合运营模式。 | 无合同主体、定价、调用量、验收、发票、回款、续费、毛利、资源成本、产能占用或客户集中度资料。 | 抽样核验前五客户合同、计量账单、调用日志、验收、发票、回款、续约及收入／毛利按 Token 服务、软件授权、整机、联合运营分拆。 |

## 决策门槛

在签约与收入承接、核心 IP／开源许可、跨 XPU 生产净收益、数据与供应权利、以及融资与控制权闭环前，只可开展非排他、可回滚的技术验证；不得设为生产单一来源、据品牌融资口径定价，或启动整体并购。
