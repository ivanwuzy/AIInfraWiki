# 沐曦集成电路关键尽调问题

> Sources: 本地横纵研究报告，2026-08-06
> Raw: [沐曦集成电路横纵分析报告](../../raw/sources/2026-08-06-沐曦集成电路_横纵分析报告.md)
> Updated: 2026-08-10

## Overview

沐曦能否成为机器人 VLA/VLM 训练、仿真数据与分布式推理的可靠第二供应商，取决于 CUDA 迁移成本、集群稳定性、C600 国产供应链量产兑现与商业化质量。以下问题在完成可复现 PoC、合同化供货与服务承诺或取得一手披露前，均不应视为已解决。

## 冲突与未确认事项

| 问题 | 支持证据 | 反对证据或限制 | 当前处理与下一步 |
|---|---|---|---|
| C600 是否已规模量产销售？ | 年报称 `2025` 年末风险量产、预计 `2026H1` 量产销售。 | “预计”不等于已规模交付；未找到逐批产量/良率披露。 | 索取批次、良率、HBM/BOM、客户验收与售后故障率。 |
| MXMACA 的 CUDA 兼容到什么程度？ | 公司称支持 `6000+` CUDA 应用、`1000+` 模型，软件栈 30 万注册用户、`5591 万` API 调用。 | 兼容范围、精度、性能和特定版本不公开；不同模型/自定义算子迁移成本可能很大。 | 以本公司 VLA/VLM 代码、容器、算子和分布式策略实测，拆为 API 编译、算子正确性、性能、分布式通信、可调试性五层验收。 |
| 千卡/万卡集群是否可复制？ | 公司称千卡商业化、推进万卡。 | 未披露每个集群的卡型、网络、有效 MFU、持续运行时间。 | 核验参考客户、集群拓扑、NCCL/MXMACA 替代层、故障恢复。 |
| 营收能否转化为稳定客户与现金流？ | 2025 营收 `16.44 亿元`、同比增长 `121.26%`，销量 >5.5 万颗。 | 仍亏损 `7.89 亿元`；客户/订单明细豁免披露，难判订单质量与回款。 | 跟踪后续年报的毛利、应收、存货减值、客户集中度与现金流。 |
| 机器人适配是否经过独立验收？ | 年报把具身智能列为前沿布局，列出“大晓机器人开悟世界模型 3.0”适配。 | 未见公开、独立的实体机器人训练/部署和安全关键推理验收。 | 做封闭 POC；明确不把云端 GPU 直接用于机载安全关键控制。 |
| 国产供应链能否保证供货？ | 公司称 C600 基于全国产工艺并在晶圆、封测、存储、EDA、IP 环节突破。 | “全国产工艺”范围、HBM 来源、产能与替代性能未充分公开。 | 在 NDA 下完成供应链、出口管制、库存与二供尽调。 |
| 早期融资时间线是否一致？ | 原报告引公司公告，列 `2021-01-20` Pre-A、`2021-03-08` Pre-A+。 | 补充报告列 `2021 年 1 月` Pre-A、`2021 年 2 月` Pre-A+，并补列 `2020 年 10 月`天使轮；月份与精确日期无法直接一致。 | 索取各轮公告、工商变更与交易文件；未核清前不据此计算累计融资、估值或股权。 |
| 万卡集群是否已落地且可复制？ | 补充报告的官网里程碑称 `2024 年`全年落地算力集群总规模“超过万卡”。 | 原报告仅称千卡商业化、推进万卡；两种表述的时间、累计/单项目范围和“落地”定义不明。 | 索取具名客户、卡型、拓扑、验收、利用率、回款及持续运行记录，不以单一规模口径计入可复制能力。 |

## 决策门槛

在问题获得可审计证据前，维持小规模、非排他 PoC 和双源策略；不把云端 GPU 直接用于机器人本体安全关键控制，不以整体收购作为获取训练能力的默认路径，不把“CUDA 兼容”或“国产”标签当作已验证的完全等价。
