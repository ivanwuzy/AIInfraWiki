## Overview

万格智元（北京）智能科技有限公司的开放问题是：品牌、融资、cPilot Runtime、GitHub 线索、客户合同和收入是否由同一可交易主体承接；以及该 Runtime 是否在目标机器人硬件上比开源和芯片原生方案形成可复现价值。在这些问题关闭前，其仅为受限的端侧推理技术观察对象。[来源：本页 Raw]

## 采购、投资与并购前验证计划

1. 调取工商登记、章程、股东名册、历次变更、商标及关联方清单，确认唯一签约、开票和资产承接主体。
2. 由投资方独立确认两次融资的基金法定名称、被投主体、签约/交割、金额、持股、优先权及资金到账；保留“千万级/数千万元级”原口径，不自行累计。
3. 审阅 cPilot/Amis 的源码、著作权、专利、员工与外包 IP 转让、开源许可证、第三方依赖、SBOM 及商业支持责任。
4. 在目标机器人 SoC/NPU 上以固定模型、量化、上下文和并发，比较 cPilot、开源 Runtime 与芯片 SDK 的峰值内存、吞吐、端到端时延、功耗、弱网降级、升级回滚和故障恢复，并保留原始日志。
5. 取得脱敏客户合同、验收、发票/回款、续约、毛利、DPA 与 SLA，区分 PoC、试用和可复制的软件收入。
