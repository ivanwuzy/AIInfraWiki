# Accelsius 主体、IP 与商业承接尽调

> Sources: [Accelsius](../companies/Accelsius.md)
> Updated: 2026-08-11

## 开放问题

任务清单指定的研究主体是 `Accelsius Holdings LLC`，但本地报告记录官网及主要公开材料使用 `Accelsius LLC` 或 Accelsius 品牌。该差异直接影响投资、并购、采购和保修责任判断。

1. Accelsius Holdings LLC、Accelsius LLC、Innventure 及任何 SPV 的完整组织图、登记信息、控制权和 cap table 分别为何？
2. NeuCool、MR250、冷板、工质、控制软件、商标、专利、制造工艺及客户数据的 IP 由哪个主体拥有或许可？
3. Series A、Series B、Johnson Controls 与 Legrand 的投资分别进入哪个主体；持股、董事席位、优先权、排他性及退出权为何？
4. TACC、Computacenter、Equinix、Nordik、iM Data Centers 与 DarkNX 的合同相对方、项目范围、验收、保修、SLA、保险和回款主体为何？
5. DarkNX 首期两座各 `65MW` 设施的融资、采购、安装、commissioning、运营数据与 Accelsius 的收入／质量责任如何证明？
6. 工质的 SDS、完整成分、GWP、PFAS／回收／运输与目标地区合规、泄漏事故处理、产品责任险和 OEM 保修立场为何？

## 决策门槛

在登记、IP／合同承接、收入与项目验收、制造及服务责任未闭环前，维持可回滚、非排他的技术 PoC；不作财务投资、整体并购或生产单源采购决定。
