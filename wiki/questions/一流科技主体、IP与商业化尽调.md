## Overview

北京一流科技有限公司／OneFlow 的投资、并购或关键训练栈采购前置问题是：品牌、开源代码和论文的权属是否归于可签约法人；框架及异构适配是否在目标机器人负载上可复现；以及 OneBrain、OneLab、OF 智能云是否构成可验证的客户、收入和 SLA 能力。这些问题未关闭前，应把 OneFlow 限于可替换的技术 PoC。[来源：本页 Raw]

## 交易与采购前验证计划

1. 取得工商档案、股东／实控人、历史增资、关联公司、域名和合同主体，核对品牌与签约责任。
2. 审阅 GitHub 管理权限、CLA／DCO、贡献者劳动或委托协议、商标、专利、软著、许可证和 SBOM，确认可转让或可持续使用的 IP 边界。
3. 取得最近 24 个月按产品、客户和合同主体拆分的收入、回款、续费、毛利、支持成本与 SLA／事故记录，并抽查合同。
4. 在固定 VLA／视觉／视频模型、batch、序列长度、网络拓扑和失败注入条件下，对 PyTorch、Paddle、MindSpore 与 OneFlow 比较吞吐、收敛、算子覆盖、迁移工时、故障恢复、功耗和 TCO。
5. 核验目标芯片／云厂商的支持矩阵、联合交付合同、版本路线图、安全响应与核心维护者留任安排；不能满足退出和可迁移要求则维持主栈基线。
