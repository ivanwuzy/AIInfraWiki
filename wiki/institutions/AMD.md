## Overview

AMD（尤其是 AMD 上海研发体系）是国内算力芯片创业公司覆盖面最广的单一人才与技术母体。截至本次整理（研究截止日 2026-08-10），沐曦（MetaX）、天数智芯（Iluvatar CoreX）、燧原科技（Enflame）三家公司的核心创始团队均可追溯到 AMD 上海研发体系的核心技术或管理岗位（关系类型 A：组织型人才母体）；壁仞科技（Biren Technology）、海光信息（Hygon）则有关键个人层面的 AMD 履历补充（关系类型 C）。AMD 是本知识库判断"哪些环节国内团队已具备独立创业能力"的重要参照系，但 AMD 与这些公司之间不存在已披露的股权、IP 授权或持续技术支持关系——AMD 的角色是人才输出方，不是投资方或技术转移方。

## AMD 上海研发体系

AMD 在上海设有研发中心，长期承担 GPU/SoC 架构设计、芯片实现、验证、量产和软件栈开发职能。是否将"AMD 上海研发中心"作为独立机构页面，需先统一部门型机构的建页规则；本页暂将其作为 AMD 正文下的一个章节处理，与"清华大学"下设二级单位的处理方式一致。

### 组织型人才母体（关系类型 A）——达到核心团队/联合创始人层级

- **沐曦（MetaX）**：陈维良（董事长、总经理；2007—2020 年任职 AMD 上海，最高至高级总监）、彭莉（联合创始人、CTO；2007—2020 年任 AMD 上海科学家；教育背景为上海交通大学硕士，教育背景不构成技术转移关系）、杨建（联合创始人、CTO；2007—2019 年任 AMD 上海企业院士；此前有威盛、亚鼎视频经历）、陈阳（CEO 助理；2015—2020 年任 AMD 上海项目经理）。证据：沐曦 2025 年年度报告，L1。详见 [沐曦（MetaX）](../companies/沐曦（MetaX）.md)。
- **天数智芯（Iluvatar CoreX）**：孙怡乐（芯片研发负责人，曾任职 AMD 上海）、刘圆（量产实现负责人，曾任职 AMD 上海）、石加圣（软件研发负责人，曾任职 AMD 上海）。公司创始人盖鲁江本人为会计、审计、资产管理背景，不属于 AMD 上海技术团队，是经营型创始人（不应与核心架构负责人混同）。证据：天数智芯港股招股书，L1。详见 [天数智芯（Iluvatar CoreX）](../companies/天数智芯（IluvatarCoreX）.md)。
- **燧原科技（Enflame）**：赵立东（联合创始人、董事长/CEO；曾在 AMD 任职约 7 年，历任计算事业部高级总监等职务；更早任职 [S3 Graphics](S3Graphics.md)，之后任紫光集团副总裁）、张亚林（联合创始人、总经理；曾任 AMD 资深芯片经理、中国研发中心技术总监）。证据：21 财经 IPO 报道、后续报道，L3；上交所项目记录可确认公司及主要负责人，完整招股书披露仍待补充。详见 [燧原科技（Enflame）](../companies/燧原科技（Enflame）.md)。

### 关键个人来源（关系类型 C）——一至数名重要人员

- **壁仞科技（Biren Technology）**：张凌岚（COO；约 14 年 AMD GPU SoC 经验，后任职 Samsung 美国研发和海光美国研发中心）。壁仞的 GPU 核心技术团队另有 S3/NVIDIA 来源（详见 [NVIDIA](NVIDIA.md)），AMD 只是补充来源之一。详见 [壁仞科技（Biren Technology）](../companies/壁仞科技（BirenTechnology）.md)。
- **海光信息（Hygon）**：黄河（中科院计算所博士；曾任 AMD 主管工程师、Imagination Technologies 高级主管工程师）、潘于（曾任 AMD 芯片设计高级经理，2025 年已离任）。海光的组织母体是中科曙光—中科院计算所（详见 [中科曙光](中科曙光.md)），AMD 履历仅为个人补充。[海光信息（Hygon）](../companies/海光信息（Hygon）.md)已建立独立公司页，本页仅保留人才关系，不据此推导持续资源供给、订单、IP 或控制权。

## 边界与避免误写

- 陈维良、彭莉、杨建、赵立东、张亚林等人的 AMD 任职是前雇主关系，不代表 AMD 向对应公司转移了 IP 或技术授权；现有证据仅支持"人才来源"而非"技术转移"。
- 盖鲁江（天数智芯）、张文（壁仞，见 [NVIDIA](NVIDIA.md)）等经营型创始人不应被误写为核心架构负责人；他们的商业/管理背景与公司 GPU 核心技术团队的 AMD 来源应分开记录。
- 海光信息的 CPU 业务存在与 AMD/x86 相关的历史授权和合作渊源，但不能因此把海光 DCU 描述为 AMD GPU 贴牌或更名产品；历史授权关系、当前控制关系、持续技术支持关系和产品架构需分别核验，本页不对此展开，具体应在海光信息公司页建立后处理。

## 冲突与不确定性

- 壁仞科技（Biren Technology）现有公司页存在一条 **Status: Disputed** 记录，涉及疑似将燧原科技的创始团队（赵立东/张亚林、2018-03 成立）信息与壁仞混淆的旧资料。本页引用的壁仞（张文/周鸿/张凌岚/肖冰）与燧原（赵立东/张亚林）人员信息来自同一份 2026-08-10 整理文档，两家公司的人员划分在该文档内部是清晰分离的，但本页不据此单方面解决壁仞公司页中的既有分歧，仅在此提示交叉核对。
