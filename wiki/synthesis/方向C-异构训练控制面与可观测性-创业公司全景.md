# 方向C：异构训练控制面与可观测性——创业公司全景扫描

> 研究日期：2026-08-14
> 研究方法：通过 Web 搜索微信公众号、36氪、投中网、钛媒体、虎嗅、投资界等创投垂类媒体，搜索有过融资或 PR 报道的创业公司
> 搜索词：异构训练调度平台、AI训练可观测性、算力调度平台、跨厂商算力统一纳管、AI集群管理平台、训练资源调度、异构计算资源管理、大模型训练运维平台、算力网络调度、云原生AI平台、GPU集群管理工具、训练监控故障诊断

- **简介**：以OrionX AI算力资源池化软件为核心，将NVIDIA GPU以vGPU、远程调用、资源调度与统一治理的方式组成数据中心资源池。Gemini AI训练平台与趋动云入口提供额外服务。核心能力包括资源发现、vGPU调度、申请/释放、队列、优先级、抢占及Kubernetes调度扩展。

- **核心产品/技术**：OrionX AI算力资源池化软件、Gemini AI训练平台、趋动云
- **与方向C的关联**：核心方向C-1（异构训练调度平台）和C-2（AI训练可观测性），OrionX提供GPU资源池化与调度，是训练基础设施的关键控制面组件

## 分析总结

本方向共找到 **30 家**有过融资或 PR 报道的创业公司。

### 按子方向分类

### 主要发现

1. **该方向竞争最激烈**：30家公司，其中10家是云原生/容器PaaS厂商转型做AI，7家是专为AI训练构建的调度平台。
2. **云原生厂商占据半壁江山**：道客、博云、灵雀云、云轴科技、青云科技、易捷行云等传统云原生厂商纷纷推出AI平台产品，但大多是"容器平台+AI扩展"，而非原生AI训练控制面。
3. **专为AI构建的控制面公司较少**：真正的AI训练控制面公司只有趋动科技、九章云极、无问芯穹、博思芯宇、基流科技等少数几家。
4. **可观测性方向存在明显缺口**：专门面向AI训练的可观测性公司极少，观测云为通用可观测性平台，博思芯宇聚焦芯片级管理，均不专门面向训练任务的可观测性需求。
5. **融资规模差异大**：云原生厂商累计融资超10亿元（道客、博云等），AI专有平台公司融资在数亿元级别，纯可观测性公司融资规模更小。
