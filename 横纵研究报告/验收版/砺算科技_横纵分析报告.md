# 砺算科技（上海砺算）横纵分析报告

> 研究截止：2026-08-06｜对象：公司（高性能图形 GPU / GPU 软件栈）｜方法：横纵分析法｜证据标记：L1=监管披露/公司一手材料，L2=具名媒体或合作方材料，L3=独立评测/社区反馈，L4=未获验证的转述。  
> **研究问题**：砺算能否从“可点亮的国产图形 GPU”走到人形机器人可依赖的推理、仿真和供应安全能力；相应应采取投资、合作、并购还是仅跟踪的动作？

## 一句话定义

砺算科技是一家由 S3 Graphics 背景团队创办、把自研图形 GPU 架构和 Windows/图形 API 兼容放在第一位的中国 GPU 公司；其首代 6nm 7G100/Lisuan eXtreme 已从工程样片进入公开发售与专业卡交付验证阶段，但其已公开的产品重心是**图形渲染和端侧推理**，不是可替代 CUDA/HBM 集群的机器人模型训练 GPU。

## 结论先行：面向人形机器人的动作建议

## 纵向分析：从 S3 老兵到首代产品上市

### 1. 起点不是“AI 热潮”，而是图形 GPU 的工程断层（2021）

砺算的前身主体**南京砺算科技有限公司**于 2021-08-11 成立；当前产品和融资承接主体**砺算科技（上海）有限公司**于 2022-04-26 成立。两者不是两个应混淆的独立项目：东芯股份的投资协议明确要求南京主体将固定资产、知识产权、技术资料、员工、债务以及客户/供应商关系向上海主体转移，说明后者是融资与经营承接平台，而不是另起炉灶的第二家公司。[东芯 2024 公告，L1](https://static.cninfo.com.cn/finalpage/2024-08-20/1220910536.PDF)

联合创始人是宣以方、孔德海（DEHAI KONG）和牛一心（I-sing Roger Niu）。早期公开访谈和报道将三人共同经历追溯到 S3 Graphics：宣以方曾参与 S3 GPU 团队，孔德海长期从事芯片研发/管理，牛一心负责过早期 3D 引擎。此类履历由公司/人物侧材料主张，虽与投资协议所列创始股东相互印证，但本报告不把“量产若干代、销售若干颗”的宣传数字作为已审计事实。[早期融资报道，2022-02-23，L2](https://www.sohu.com/a/524967812_121124379)

他们选择的是最难也最具体的切口：不先做数据中心训练加速卡，而是自研 ISA、计算核心、驱动和图形 API 兼容的 **TrueGPU**，先进入 PC/工作站、数字孪生、云桌面、云游戏、XR 和座舱。这个选择的好处是 DirectX、Vulkan、OpenGL 所代表的成熟软件存量提供了明确验收目标；代价是驱动质量、游戏/专业软件白名单与长期维护会比单一封闭工作负载更难，且不会自动长出 CUDA 生态。

### 3. 从“2023 量产目标”到 G100 点亮：产品周期比口号更长（2022—2025）

2022 年材料曾预期 G100 于 2023 年进入市场，且声称架构可扩展至 16,384 个计算核心。[Pre-A 报道，L2](https://i.ifeng.com/c/8JxxUxZ47tt) 直到 2024-08，创始人仍称芯片处于 IP 集成和流片前最终验证阶段；其访谈承认国产 GPU 在生态上与 NVIDIA 有明显差距，也把 DirectX 12 兼容作为破局点。[财联社访谈，2024-08-26，L2](https://www.cls.cn/detail/1776756) 这构成一次实质延期：从“2023 上市”到 2025 年回片，不应在报告中掩盖。

关键转折发生于 2025-05-24/25。东芯收到上海砺算告知：首批已封装 G100 芯片到货，24 小时内启动功能测试，25 日完成主要功能测试且“结果符合预期”；同一公告同时明确完整功能、性能、可靠性、良率和客户导入仍未完成。[东芯公告，2025-05-27，L1](https://static.cninfo.com.cn/finalpage/2025-05-27/1223684884.PDF) 这比单纯发布会更有价值：至少说明首代硅已点亮，但不能据此外推性能、良率或大规模销售。

公司之后把产品命名为 **7G100** 芯片和 **Lisuan eXtreme（LX）** 显卡系列，并在官网称其为自研 TrueGPU“天图架构”、自研指令集和软件栈。官网 2026 年回顾给出的节奏是：2025-05-24 回片、24 小时点亮、2025-07-26 发布 7G100、2025-09 完成量产片流片、2026-02 量产片回片、2026-03-12 公开发售。[公司新闻，2026-03-13，L1（公司声明）](https://www.lisuantech.com/about/news/27) 这里的“2025-07 发布”与其新闻页显示 2025-08-04 的发布日期存在网页发布/活动日期差异，故本报告同时保留两者而不虚构唯一日期。

### 4. 现在卖什么、能做什么、不能据此推断什么（2026）

公开消费卡 **LX 7G100** 为 12GB GDDR6、四个 DP 1.4a，标称支持 DX12/Vulkan 1.3/OpenGL 4.6/OpenCL 3.0、8K60 显示和 HEVC 编解码；官网把游戏、内容创作、AIPC 本地模型作为场景。[产品页，L1（公司声明）](https://www.lisuantech.com/product/gaming-graphics/lx-7g100) 专业系列的 LX PRO/ULTRA 则将 24GB GDDR6、服务器/工作站、SR-IOV 虚拟化、数字孪生作为卖点；ULTRA 页面标称最高 24 TFLOPS FP32 和 16 路虚拟 GPU。[ULTRA 产品页，L1（公司声明）](https://www.lisuantech.com/product/professional-graphics/lx-ultra)

公司的软件方向同样值得区分。官网介绍了 LSRT 推理引擎及 TVM 后端扩展，并宣称 NRSS 超分辨率、智能任务分配、双发射、乱序渲染等能力。[技术页，L1（公司声明）](https://www.lisuantech.com/innovation) 这些材料能证明公司**意图和产品接口**，不能证明它已经拥有 PyTorch/CUDA 等价的训练栈、主流 transformer 算子覆盖、分布式通信或 HBM 集群能力。对机器人公司而言，后者才决定大模型训练和大规模 VLA 迭代是否可迁移。

### 6. 市场的第一声回音：可用性进步，性价比和软件仍在补课

公司公开发售说明至少让外部评测成为可能。Tom’s Hardware 转引潮玩客在 9800X3D 平台、1080p 多游戏实测：LX 7G100 在表列游戏中能运行，但低于 RTX 4060、Arc B580、RX 6600 XT；文章还指出 3299 元/约 485 美元定价会削弱消费者价值主张。[2026-05-21，L3](https://www.tomshardware.com/pc-components/gpus/chinas-new-homegrown-gaming-gpu-flops-in-performance-and-price-flagship-usd485-lx-7g100-cant-keep-pace-with-nvidias-older-rtx-4060) 另一家中文媒体转述 18 款游戏测试为约 RTX 3060 的三分之二，并明确指出未经专门驱动优化。[游侠网，2026-05-22，L3/L4（转述 UP 主）](https://www.ali213.net/news/html/2026-5/1013083.html)

相反，游民星空的 19 款游戏评测给出更正面结论，认为 1080p 多数项目可达 60FPS，并指出 GPU-Z/AIDA64/HWiNFO 尚不能完整识别信息，专业软件适配仍需时间。[2026-05-26，L3](https://www.gamersky.com/hardware/202605/2145083_12.shtml) 两者并不形成“谁对谁错”的结论：它们的游戏、画质、超分/帧生成设置、驱动版本不同。共同的高信号事实是：**首代卡已能跑现代软件；性能和工具/驱动成熟度尚未证明可以按国际同价主流卡采购。**

公开可检索的真实开发者反馈仍高度集中在游戏与装机社区；未发现可复现的 PyTorch、TensorRT 替代、VLA/VLM 或机器人中间件长期部署评测。这个缺口不能用公司 “AIPC/DeepSeek 支持” 宣称补上。

## 横向分析：砺算处于哪一张竞争图谱

砺算并非与一个单一对手竞争，而是在两个不对称市场同时作战：一侧是 NVIDIA/AMD/Intel 的成熟 PC/专业图形生态，另一侧是摩尔线程、壁仞等国产 GPU 的自主可控和算力叙事。选取五个代表者如下。

| 玩家 | 路线与当前生态位 | 与砺算的真实差异 | 对砺算/机器人的含义 |
|---|---|---|---|
| NVIDIA | CUDA + RTX/专业卡/数据中心纵向生态，图形、推理与训练连成一体。 | 砺算公开目标是 DX/Vulkan/OpenGL 图形兼容和本地推理，未公开 CUDA 等价迁移、HBM/多卡互联或训练集群产品。 | NVIDIA 是机器人训练/仿真/部署的性能和工具链基准，也是供应受限风险来源；砺算当前只能作为部分边缘/图形工作负载备选。 |
| AMD | Radeon 图形与 ROCm 开源计算栈并行发展。 | 同样有图形起点，但 AMD 具备更长的开发者、服务器和 AI 加速产品线；砺算的优势只可能来自本地化交付、自主 IP 与国产化集成，尚未由 TCO 证明。 | 可将 AMD 作为“非 CUDA 迁移难度”的对照，不能将 API 兼容误认为深度学习框架可迁移。 |
| Intel | Arc/Xe 图形卡与 oneAPI 计算软件栈。 | Intel 展示了后来者在驱动、游戏兼容和开发工具上需要多年迭代；砺算的 WHQL/公开售卖是必要里程碑，不是终点。 | 用 Intel 的驱动成熟路径校验砺算团队是否有持续软件预算，而非只看首片规格。 |
| 摩尔线程 | 国产全功能 GPU，消费级 MTT 系列与数据中心/AI 产品并行，建设 MUSA 软件栈。 | 与砺算同样面对国产图形和生态适配，摩尔线程进入市场较早、产品线更广；砺算强调自研图形渲染、端云边定制，首代消费卡公开实测是其最直接的比较对象。 | 两者均可纳入国产渲染/边缘推理 POC；应以模型吞吐、稳定性、驱动响应和供货，而非“国产”标签选型。 |
| 壁仞科技 | 高端通用计算/AI 加速器优先，面向数据中心算力。 | 不是消费图形卡的同位竞品，却是砺算若声称进入 AI 训练时的更强替代选项；壁仞的核心约束也在供应链、软件和客户验证。 | 训练芯片尽调应把壁仞等作为路线对照；砺算的图形架构不应被直接抬升为训练替代。 |

### 用户选择的不是“峰值算力”，而是可预测的工作结果

NVIDIA 的用户购买的是 CUDA、框架、工具、案例和开发人员存量；AMD/Intel 用户在权衡价格、图形性能与迁移成本；国产 GPU 的早期用户更常为信创、供应安全、定制和本地交付付费。砺算的 12GB 消费卡与 24GB 专业卡说明其最有希望赢得的并非前沿训练，而是“要在 Windows/国产 OS、图形软件、数字孪生、云桌面和端侧模型中跑起来”的中间地带。

但它不能同时借用两种市场的溢价：在消费市场，L3 数据显示 3299 元与性能不匹配会压低需求；在政企市场，卖点必须从“国内领先”变为可验收的应用稳定性、驱动 SLA、兼容认证、虚拟化隔离和长期供货。飞渡一体机是较好的起点，真正的壁垒则是重复部署和客户愿意付费续订。

### 面向机器人工作负载的横向结论

人形机器人需要的不是一个抽象“GPU”：离线训练通常受显存容量/带宽、分布式通信、框架和集群软件制约；仿真、数字孪生和合成数据偏图形渲染与物理/视觉管线；机载/边缘推理偏功耗、延迟、算子和可靠性。砺算的公开产品证据较强地覆盖第二项的一部分和第三项中**非安全关键、本地小模型**的一部分，几乎未覆盖第一项。因此其主战场应是机器人研发基础设施的渲染/可视化和端边探索，而不是替换训练集群。

## 横纵交汇：历史如何塑造今天的位置

砺算早期“从图形 API 切入”的决策，决定了它今天既有优势也有边界。优势来自 S3 经验所对应的图形驱动、显示和渲染工程文化：首片从回片到点亮、到公开运行现代游戏，至少证明公司不是只做 PPT 的 GPU 项目。边界也来自同一选择：图形软件生态在 Windows 端已有清晰标准，却不会自动生成大模型训练所需的编译器、框架、通信与客户代码资产。

2023 目标未兑现、2024 财务承压，反过来解释了为什么东芯这类存储厂商的战略资金如此关键。东芯投资协议中明确提出 DRAM 与图形芯片协同、软硬件适配和工艺优化的可能性；这为砺算带来了持续资金和存储协同想象，但也把它推入了“首片成功后必须尽快量产、导入和再融资”的钟摆。首代在公开游戏实测中的落差正说明：晶体管与驱动的长期投入都不能靠一次流片完成。

我的判断是，砺算最可贵的资产不是“首代卡对标哪个 RTX”，而是完整图形 GPU 团队、实硅带回来的验证闭环及面向图形行业的合作入口。其最危险的误区则是把这些资产直接包装成通用 AI 训练能力。对本公司的最佳策略是让它在窄而真实的工作负载中赢一次，再讨论扩大关系。

### 三种剧本（非预测，附可观察信号）

1. **最可能：图形国产化的窄市场站稳。** 砺算继续迭代驱动和专业卡，在数字孪生、信创工作站、云桌面/云渲染中取得少量但可重复的政企订单；消费卡成为生态/品牌入口而非主要利润池。信号：飞渡等伙伴公布独立认证、客户复购、专业应用兼容列表与稳定驱动节奏。
2. **最危险：首代之后的现金—生态双重缺口。** 性能价格倒挂、良率或 GDDR 供应压力、驱动 bug 和缺少具名订单使收入迟到；GPU 研发的固定成本迫使再融资，东芯及其他股东面临投后管理与稀释压力。信号：下一代流片延误、频繁降价但无企业订单、研发人员流失、审计持续经营压力重现。
3. **最乐观：从渲染 GPU 延展到“渲推一体”的本地化平台。** 通过飞渡等伙伴形成专业软件认证，LSRT/TVM 后端获得可重复的端侧模型性能，专业卡在机器人数字孪生、视觉质检、XR 和边缘私有化部署中形成组合销售。信号：开源/文档化 SDK、主流框架后端、独立模型基准、多个非关联客户和明确的下一代显存/能效改进。

## 方法说明

本报告按横纵分析法：纵轴追溯团队、融资、产品和商业化的因果链；横轴将其置于国际图形生态和国产 GPU 替代路线中比较。所有公司性能、合作和市场份额式表述均按证据等级保留边界；没有公开证据的部分明确列为未知，而非以行业常识补写。

## 产业链分类复核

**唯一主分类：1.8 图形GPU（桌面／工作站／专业可视化）。**

理由不是公司把“AI”写入营销，而是其可识别的核心价值创造是自研完整 GPU 芯片和图形卡：从计算核心/指令集、GPU 架构、投片量产到消费卡和专业卡销售；其产品同时提供图形渲染和通用计算/推理接口，专业卡又直接服务服务器和边缘部署。首代的商业重心明确偏图形渲染，且以 PC/工作站、数字孪生、云桌面、云游戏、XR 和座舱为先，因此新增的 1.8 比 1.1 更准确；这不否认其未来可拓展 AI 计算。

**次分类：2.1 加速计算平台（CUDA-like）——仅作次要。** 理由是公司宣称自研软件栈、LSRT 推理引擎和 TVM 后端，且产品以 OpenCL/API 兼容向应用提供计算能力；但截至研究日，公开证据不足以表明它已形成可与 CUDA 相当的独立开发者平台、框架迁移和训练生态，因此不能取代 1.1 成为主分类。

**与总表暂定归类的比较与建议：** 总表应更新为“1.8 图形GPU；2.1 加速计算平台（待核验）”。砺算是“图形渲染优先、兼具端侧推理”的 GPU；不要把 2.1 扩张解释为已验证的 CUDA 替代或训练集群软件栈。
