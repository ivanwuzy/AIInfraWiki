# 来源原文：vLLM Documentation

Source URL: https://docs.vllm.ai/en/latest/

Accessed: 2026-08-09

> vLLM is a fast and easy-to-use library for LLM inference and serving.

> The documentation lists online serving, deployment, observability, benchmarking, OpenAI-compatible API server, distributed parallelism, quantization, speculative decoding, and integrations.

> vLLM documents support across hardware including NVIDIA, AMD, Intel Gaudi, IBM Spyre, Huawei Ascend, Rebellions NPU, Apple Silicon and MetaX GPU.

Source note: vLLM 官方文档用作自建/开源推理平台路线的对照，不代表某一硬件或模型在任何生产工作负载下的实际性能、稳定性或国产芯片支持成熟度。
