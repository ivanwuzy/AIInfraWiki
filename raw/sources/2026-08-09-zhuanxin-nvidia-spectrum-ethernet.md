# 来源原文：The NVIDIA Spectrum Ethernet Platform

Source URL: https://www.nvidia.com/en-us/networking/products/ethernet/

Accessed: 2026-08-09

> NVIDIA Spectrum Ethernet is a standards-based, end-to-end platform that includes Spectrum switches, NVIDIA ConnectX SuperNICs, NVIDIA BlueField DPUs, LinkX cables, and networking software.

> The NVIDIA Spectrum-X Ethernet platform is purpose-built to drive generative AI at unprecedented scale—boosting network performance by 1.6x and sustaining breakthrough 95% efficiency across deployments exceeding 100,000 GPUs.

> The NVIDIA Spectrum Ethernet switch family includes a switch and software portfolio spanning 1GbE to 800GbE.

> Combining Spectrum switches with the NVIDIA Cumulus Linux network operating system (NOS), NVIDIA Pure SONiC NOS, NVIDIA NetQ validation toolset, and NVIDIA DSX Air simulation platform delivers the performance and features that every data center needs.

Source note: 以上性能为 NVIDIA 自述；本研究仅用其证明“硬件、NIC/DPU、NOS、可观测与仿真软件合为可交付平台”的对照维度，不据此推导目标公司的性能。
