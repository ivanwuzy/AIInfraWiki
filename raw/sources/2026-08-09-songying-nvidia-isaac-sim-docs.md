以下为官方文档首页正文原文摘录：

> Import robots and scenes from URDF, MJCF, Onshape CAD, or USD. Simulate with PhysX or Newton, add RTX and physics-based sensors, generate synthetic data, prepare robots for Isaac Lab, and validate robot stacks with ROS 2.

> Isaac Sim Workflow Overview: Import Scenes, robots, sensors, assets; Configure; Simulate; Connect / Deploy.

> For SDG, label the scene, vary the environment, and write datasets. For SIL, configure robot physics, sensors, and communication graphs, then validate the external robot stack before hardware.

> Synthetic Data Generation: Perception Data Generation (Replicator).

> ROS 2: URDF Importer Extension; USD to URDF Exporter Extension; ROS 2 tutorials and bridge material.

采集限制：该文档只用于说明 Isaac Sim 的公开产品边界和生态接口，不构成对 ORCA、任何中国 GPU 或任何特定机器人工作负载的性能比较。
