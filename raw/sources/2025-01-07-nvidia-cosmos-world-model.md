# Cosmos World Foundation Model Platform

> 来源：NVIDIA, arXiv:2501.03575
> 日期：2025-01-07（v1）/ 2025-03-18（v2）/ 2025-07-09（v3）
> 标签：Cosmos, 世界模型, WFM, 视频预测, NVIDIA, 物理 AI

## 模型架构

### 扩散模型 WFM
- **两个变体**: 7B 和 14B 参数
- **架构**: DiT（Diffusion Transformer），3D patchification（patch size: pt=1, ph=pw=2）
- **7B 配置**: 28 层，model dim 4096，FFN dim 16384，32 注意力头
- **14B 配置**: 36 层，model dim 5120，FFN dim 20480，40 注意力头
- **AdaLN-LoRA**: 将 7B 参数从 11B 降至 7B（减少 36%）
- **位置编码**: 混合 3D 分解 RoPE + 可学习绝对位置编码
- **QK 归一化**: 使用 RMSNorm 确保训练稳定性
- **文本编码器**: T5-XXL，通过交叉注意力注入
- **分词器**: Cosmos-Tokenize1-CV8×8×8-720p（连续 token）
- **公式**: EDM 基础，不确定性加权噪声层级平衡

### 自回归模型 WFM
- **两个变体**: 4B 和 12B 基础模型 → 添加交叉注意力后为 5B 和 13B Video2World
- **架构**: Llama3 风格 GPT 模型，从头训练用于视频预测
- **分词器**: Cosmos-Tokenize1-DV8×16×16-720p（离散 token，FSQ）
- **扩散解码器**: 7B 参数，将离散 token 映射到连续 token 空间

### 分词器架构
- 注意力基础编码器-解码器，因果时间设计
- 输入先经过 2 层 Haar 小波变换
- 时空分解 3D 卷积 + 因果自注意力
- 压缩率: 视频 4×8×8、8×8×8、8×16×16；图像 8×8、16×16

## 训练计算需求

### 集群规模
- **10,000 块 NVIDIA H100 GPU，历时 3 个月**训练所有 WFM 模型

### 渐进式训练阶段（扩散 WFM）

| 阶段 | 分辨率 | 帧数 | 序列长度 | FSDP 大小 | CP 大小 |
|------|--------|------|---------|-----------|---------|
| 低分辨率预训练 | 512p (640×512) | 57 | 10,240 | 64 | 2 |
| 高分辨率预训练 | 720p (1280×704) | 121 | 56,320 | 64 | 8 |
| 高质量微调 | 720p (1280×704) | 121 | 56,320 | 64 | 8 |

### 超参数
- 7B: LR=2^(-15), weight decay 0.1, AdamW β=(0.9, 0.99), ε=1e-10
- 14B: LR=2^(-16), weight decay 0.2, 同上 AdamW
- 线性 LR warmup 2,500 步
- 微调: ~10k 步，线性衰减 LR

## 训练基础设施

### 数据处理
- **Ray-based 编排管道**（AnyScale Ray）
- **Fragmentation Gradient Descent 算法**扩展用于多资源调度
- **GPU 加速**: 使用 NVDEC/NVENC 硬件编码器
- **PyNvideoCodec + ffmpeg**: 实现约 6.5× 吞吐量提升
- **VILA 标注**: FP8 量化 TensorRT-LLM 引擎，相比 PyTorch half-precision 基线实现 10× 加速

### 分词器运行时（A100 80GB）
- Cosmos CI 8×8: 77M 参数，62.7ms/图像
- Cosmos DI 8×8: 79M 参数，64.2ms
- Cosmos CV 4×8×8: 105M 参数，34.8ms/帧

## 数据规模

- **原始数据**: 约 20M 小时原始视频，分辨率 720p 到 4k
- **数据分类**: 驾驶 11%、手部运动/物体操作 16%、人体运动 10%、空间感知/导航 16%、第一人称 8%、自然动态 20%、动态相机 8%、合成 4%、其他 7%
- **策划输出**: 约 10^8 视频片段用于预训练，约 10^7 用于微调
- **片段长度**: 2 到 60 秒
- **去重**: 移除约 30% 训练数据；k-means k=10,000 聚类，RAPIDS GPU 加速实现

## 已识别的瓶颈与挑战

1. **视频编解码异构性**: 多种编码格式，统一转码为 h264_nvenc 解决
2. **ffmpeg NVDEC/NVENC 利用率问题**: 替换为 PyNvideoCodec
3. **训练不稳定**: 注意力 logit 早期增长不稳定 → QK 归一化解决
4. **Loss 尖峰**: 低 beta 和 eps 的 AdamW 显著减少 loss spikes；14B 模型极少遇到
5. **图像-视频分布不匹配**: 视频隐空间的非平稳统计 → 逐帧和逐通道标准化
6. **收敛差异**: 视频批次去噪 loss 收敛慢于图像批次 → 缩放视频噪声水平
7. **AdaLN 参数开销**: DiT 的 AdaLN 层占显著参数 → LoRA 分解解决
8. **文本领域差距**: VLM 生成的标注与用户提示不同 → prompt upsampler LLM 解决
9. **视频生成质量 vs 图像**: 高质量视频数据不足导致低 guidance 设置下视频质量次优
10. **分词压缩权衡**: 过度压缩丢失视觉细节 → 为自回归模型构建扩散解码器
