### 嵌入式软件开发工程师｜北京、上海、深圳

岗位职责：

1. 参与下一代AI网卡软件架构、API设计和研发
2. 负责AI网卡嵌入式软件的设计和实现
3. 负责RDMA和TCP/IP等网络协议栈在芯片和FPGA上的研发
4. 负责AI网卡设备管理、监控等模块的开发

任职资格（节选）：精通 Linux 下 C/C++ 编程；精通嵌入式设备软件开发；熟悉 Linux 内核及内核设备驱动程序；熟悉 RDMA、TCP/IP 等网络协议。加分项包括 RISC-V 和 ARM 架构开发经验、嵌入式实时操作系统研发经验。

### Linux软件研发工程师｜北京、上海、深圳

岗位职责：

1. 参与下一代AI网卡软件架构、API设计和研发
2. 与硬件和应用团队合作，制定各类软硬件编程接口
3. 负责RDMA和TCP/IP网络协议栈研发
4. 负责AI网卡网络通信库及Runtime的开发

任职资格（节选）：精通 Linux 下高性能网络程序原理及开发；熟悉网络协议如 RDMA，TCP/IP，以太网；熟悉 Linux 内核及网络协议栈研发。

### Linux内核研发工程师｜北京、上海、深圳

岗位职责：

1. 参与下一代AI网卡软件架构、API设计和研发
2. 与硬件团队合作，制定软硬件编程接口
3. 负责AI网卡内核协议栈研发，包括RDMA和TCP/IP研发
4. 负责AI网络驱动程序研发

### 验证工程师｜北京、上海、深圳

岗位职责：负责芯片系统级/模块级验证；制定验证策略和计划，进行测试功能点分解，搭建仿真验证环境；开发参考模型和测试向量，进行回归测试，协助调试；进行覆盖率收集和分析，保障验证质量。

加分项：有网卡/智能网卡/DPU、交换机、路由器等网络硬件验证经验。

### ASIC设计工程师｜北京、上海、深圳

岗位职责：

1. 架构设计，包括软硬件整体架构设计、软硬件接口设计、芯片和板级硬件架构和微架构设计
2. 前端设计，包括FPGA和芯片RTL设计与实现
3. 设计验证，包括simulation、emulation和prototyping
4. 设计建模，包括行为模型和性能模型

任职资格（节选）：熟悉网络协议如 RDMA，TCP/IP，IPv6，以太网；熟悉计算机体系结构和常见的总线协议。

### FPGA设计工程师｜北京、上海、深圳

岗位职责：参与 FPGA 架构设计，包括整体方案和架构设计，产品特性和规格的制定；负责 RTL 设计，包括系统级和模块级功能设计和验证，性能和资源优化；参与软硬件系统集成、调试和性能优化。

任职资格（节选）：熟悉网络协议如 Ethernet、IPv4/IPv6、RDMA、TCP/IP。加分项：有网卡/智能网卡/DPU、交换机、路由器等网络硬件研发经验。
