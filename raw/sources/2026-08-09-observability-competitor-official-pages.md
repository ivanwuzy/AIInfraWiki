# 可观测性横向比较：官方产品页面摘录

> Source: https://www.datadoghq.com/product/ ; https://grafana.com/oss/ ; https://www.elastic.co/observability ; https://help.aliyun.com/zh/arms/
> Collected: 2026-08-09
> Published: Unknown（产品页）

以下是横向比较使用的官方页面公开表述摘录。

## Datadog

Datadog 产品页将其描述为：`The monitoring and security platform for cloud applications.` 页面导航列出 `Infrastructure Monitoring`、`Application Performance Monitoring`、`Log Management`、`Digital Experience Monitoring`、`Cloud SIEM`、`LLM Observability`、`Incident Management` 等产品类别。

## Grafana

Grafana OSS 页面写道：`Grafana OSS is the open source visualization and analytics software for metrics, logs and traces.` 页面并列 Grafana、Prometheus、Loki、Tempo、Pyroscope、OpenTelemetry Collector，并将该组合表述为开放的 observability stack。

## Elastic

Elastic Observability 页面写道：`Unify logs, metrics, traces, and more on a single platform.` 页面将 APM、日志、基础设施监控、synthetics、real user monitoring 和 OpenTelemetry 置于同一 observability 产品组合中。

## 阿里云应用实时监控服务 ARMS

阿里云 ARMS 文档首页将产品描述为应用性能管理服务，文档目录包含应用监控、Prometheus 监控、前端监控、可观测告警、链路追踪、日志关联分析等内容。

上述摘录只用于产品路线比较；它们不构成各厂商性能、市场份额、客户规模、价格、数据主权或对人形机器人训练负载适配性的独立比较证据。
