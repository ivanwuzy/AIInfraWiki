# SONiC README

> Source: https://github.com/sonic-net/SONiC/raw/master/README.md
> Collected: 2026-08-09
> Published: Unknown（持续维护的主分支文件）

Software for Open Networking in the Cloud（SONiC）是基于 Linux 的免费、开源网络操作系统，可运行在多家厂商的交换机和 ASIC 上。README 将其描述为具有 BGP、RDMA 等网络功能，采用容器化、模块化架构，提供标准 Linux 接口和工具；项目文档包含安装、开发者指南、治理、架构和 API 等内容。项目采用 Apache 2.0 许可证。

该上游项目说明支持“SONiC 本身是多厂商、可运行于多 ASIC 的开源 NOS”，不支持任何一家商业发行版的兼容度、稳定性、客户部署或性能结论。
