> 2026-08-07 11:07｜趋境科技与商汤科技达成战略合作，共建日均十万亿级“高品质 AI Token 工厂”：近日，趋境科技与商汤科技大装置签署战略合作协议，联合打造日均十万亿级“高品质 AI Token 工厂”；首条共建产线已具备日均万亿级 Token 的稳定生产与消纳能力并正式上线。双方将结合趋境科技在国产芯片适配、推理优化和 Token 运营方面的能力，以及商汤大装置的大模型、基础设施与产业应用积累，重点推进异构 Prefill-Decode 协同、KV Cache 传输复用和软硬件适配，让不同硬件承担最适合的推理阶段任务，并面向企业服务、智能体和行业模型等场景持续扩展产能。

> 2026-07-22 12:00｜趋境科技华东区域总部落地钱江世纪城，五年内建成万卡级高品质 AI Token 工厂：2026 年 7 月 21 日，趋境科技与萧山区钱江世纪城签署产业投资合作协议，华东区域总部正式落地杭州。公司将在当地建设 ATaaS 华东区域交付与服务中心，围绕企业级 AI 推理需求提升区域交付和技术服务能力，并计划五年内建成万卡级高品质 AI Token 工厂。

> 2026-06-17 14:57｜趋境科技 Day 0 支持 GLM-5.2：ATaaS 平台 Token 服务上线，KTransformers 同步适配：智谱 AI 开源 GLM-5.2 后，趋境科技作为首批生态支持方实现 Day 0 接入：ATaaS 高效能 AI Token 生产服务平台同步上线 GLM-5.2 Token 服务。开源项目 KTransformers 也完成适配，可基于 SGLang + KT-Kernel 以 FP8 或 BF16 方式运行模型，并通过 OpenAI 兼容 API 接入本地应用与 Agent 工作流。

> 2026-06-09 11:49｜趋境科技 × 上海人工智能实验室：基于 DeepLink 与 Mooncake，共建国产异构综合推理生态：上海人工智能实验室开源 DeepLink 智能流量路由系统 DLRouter 及多元算力混合推理方案，趋境科技将基于 Mooncake 与 DeepLink 团队展开深度合作。DLRouter 负责跨芯片请求路由，根据 KV Cache 状态、序列长度与推理阶段完成最优分流；Mooncake 提供跨节点全局 KV Cache 池、前缀复用、热点副本与多级缓存能力。双方将打通国产异构芯片间的缓存适配，减少重复预填充和负载倾斜，并共同探索跨机房、跨地域的综合推理协同。

> 2026-05-27｜Mooncake 携手 llm-d 亮相 vLLM Meetup，探索 Agentic AI 时代大规模推理新范式：5 月 23 日，趋境科技受邀参与 vLLM 社区在杭州主办的技术 Meetup，与红帽、NVIDIA、月之暗面等企业专家共探 Agentic AI 时代大模型推理系统的架构演进。趋境科技卢佳豪与 llm-d 社区核心维护者 Greg Pereira 联合分享，介绍了 llm-d 融合分布式推理与 Kubernetes 运维的技术底座，以及 Mooncake “以存换算” 的核心理念，其通过 TENT 传输引擎和分层存储实现 KV Cache 高效存储与传输。
