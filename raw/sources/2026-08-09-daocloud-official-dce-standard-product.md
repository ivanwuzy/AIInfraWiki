DaoCloud Enterprise 5.0 Standard: This edition offers a production-grade cloud native foundation compatible with various infrastructures. It supports x86 and ARM architectures, cloud edge collaboration, and simplifies large-scale cluster creation and management. With CI/CD pipelines, it automates application delivery and deployment, while the innovative GitOps system ensures progressive delivery. The integrated App Store provides a comprehensive software stack spanning over ten categories for enterprises.

Enterprise-grade Kubernetes platform: This platform enables fast and flexible application development, workflow, and deployment across diverse environments. It comprises container runtime, network, storage, monitoring, registry, load balancer, DNS, and authentication, assuring robust operation across bare metal, public/private/hybrid clouds.

Efficient and automated application delivery process supports self-service migration to cloud: Leveraging cloud native CI/CD pipelines, it integrates an extensive toolchain and enables efficient parallel execution of pipelines to automate application construction and deployment. GitOps and progressive delivery capabilities support application deployment. Tenant permission division can adjust to users’ organizational structures and enables tenants to independently deploy applications to the cloud through self-service.

Cloud edge collaboration supports unified scheduling and management of heterogeneous resources: A lightweight, hardware-compatible edge system supporting x86 and ARM offers standard device interfaces for seamless integration and unified cloud management, monitoring, and operations. It enables batch deployment and upgrades for same-architecture nodes, with a visual deployment view for synchronized status tracking.

App Store integrates hundreds of partner applications: networking, storage, big data, edge IoT, and security templates sync to the cluster. Every operation is automatically documented, and operation logs are presented visually.
